# 播放访问与云盘下载工作台

2026-10-14 · 0.24.0-dev · migration47

- 系统设置可回显/编辑可信反代 CIDR；默认不信任任何转发头。仅在连接来自明确可信代理时从右向左解析全部 X-Forwarded-For。逐次访问记录同时显示访客地址、连接地址、来源与公网属性；历史记录无代理证据不追溯伪造。非公网/缺少头/无效链如实显示，不把服务器出口IP当访客IP。
- 播放器访问页按已核验 Emby 用户ID筛选，也可只看未知身份。用户名称相同仍按ID区分；独立STRM请求不会借用其他请求的用户。
- 搜索结果带媒体身份时，下载弹窗直接回显TMDB ID、类型、标题、原名及年份，无需重新搜索/点击条目。仅缺身份或明确更正时查询TMDB；服务器继续核验真实身份和搜索快照，并拒绝未声明的身份变化。
- 下载器状态同步与重试提交分离。刷新只观察已存在任务，不重新加种。未知进度为null，实际零仍是0%，失败保留最近有效进度与时间，显示错误。速度、连接数、qB状态、Hash及完整任务字段可查看；每15秒cron继续同步。
- 云盘索引中候选文件及已入库资产均可批量选择1–20项同一115连接的文件，进入现有批次工作台。已确认身份优先回显，保留季0/明确集数；默认命名模板可查看，多集文件需自定义完整名称。预览绑定提供方文件ID及大小，变更后需重做预览。执行仍走既有冲突/扫描/传输/托管输出保护和持久化批准队列；移动只更新索引路径，保留媒体资产及文件Key。

真实下载诊断：本次测试种子的Tracker曾返回 `Port 6881 is blacklisted`。测试下载器监听端口改为49161，原种子不重新添加。原种子随后真实下载100%，Tracker恢复正常（89做种者，4下载者的当次快照）；既有任务随后上传/校验/Emby确认。客户端解码播放未据此宣布通过。最终连接与进度以部署验收收据为准。

管理员连接编辑自动回显已保存的可解密参数，可主动隐藏；未修改值不重复提交，关闭窗口清空内存。登录密码为不可逆哈希，不支持虚构原密码回显。

验收修正：云盘索引勾选候选或资产后暂停页面轮询刷新，避免10秒轮询清空选择。明确手动刷新/完成批次后更新列表；后台cron扫描仍正常执行。已增加跨轮询周期的浏览器回归。

补充并发保护：已经发出的列表刷新响应也不会覆盖请求期间新增的勾选；明确手动刷新或完成批次才清空选择。候选和已入库资产采用同一保护，浏览器回归包含受控延迟响应。
