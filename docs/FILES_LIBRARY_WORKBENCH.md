# 文件与入库工作台

2026-10-14 · 0.19.0-dev · 数据库迁移42

## 使用顺序

1. **文件管理**：随程序挂载自动出现本地根目录，CloudDrive2提供115根目录。当前目录及每个文件显示能力/保护原因；下载与做种源只读，托管STRM需走输出流程。私密日志、恢复文件、数据库目录、Docker Socket和宿主根不可访问；符号链接仅显示名称。
2. **云盘索引**：选允许子目录扫描，查看当前目录、文件数、已完成/已知目录、连接修订、对账代次和目录游标。可暂停、取消、重新完整对账；cron/变化推送沿用扫描计划。已知目录进度不是预先已知的全树百分比。
3. **识别确认**：核对现有索引文件ID/路径/大小/已知哈希，0day信息仅作提示。唯一精确标题或原名+年份+类型可预选TMDB结果，仍需人工确认。批量入库须逐文件确认实际季集，样片和未知合集覆盖不自动推断。确认前重新观察云端文件；变动使预览无效。
4. **分类整理**：勾选1–20个普通文件，默认使用系统电影/剧集模板，或逐项自定义完整文件名；支持分类/重命名/移动。先保存逐项旧→新预览，展示字幕/NFO及目录创建。任一冲突阻止整批批准。批准摘要+TTL校验后进入同一app的library队列。
5. **托管输出**：STRM管理显示文件级资产集合、STRM/NFO/字幕归属、云端状态和Emby证据。输出修复、身份/季集修正、布局迁移、归档保留期和清理使用现有日志/预览/明确批准，不覆盖手工或无归属文件。固定STRM内容及播放Key不随文件整理轮换。
6. **上传与入库**：下载原文件持续保留做种。上传字节、云端大小/可用哈希校验、输出写入、Emby逐路径可见各是独立事实。恢复会话/未知结果读回及入库单独批准沿用传输任务；已有绑定的云端路径不能被另一个文件重绑定。
7. **Emby确认**：定向提交托管路径更新通知，再逐路径查询，不发送全库刷新兜底。指定用户使用系统设置中的Emby用户ID；可见性记录绑定资产修订、Emby连接修订和用户范围，任何范围改变都显示待重新确认。可见不等于原生/浏览器完整解码，302不兜底转码。
8. **历史与恢复**：统一按阶段、状态、媒体/来源关键字、批次和时间筛选扫描、文件整理、上传、输出/归档和Emby事实。逐步骤只将已写日志的步骤视为完成。结果未知选择“核对结果（不重放）”，未执行的剩余项需新预览，不会自动继续旧批次。

## 持久化与边界

- PostgreSQL：file_operations、file_batches/items/parents、library_scans/directories/seen、library_candidates、transfer_tasks、media_artifact_journal、library_emby_checks、audit_logs/outbox。
- Redis只缓存，不保存批准事实或取代扫描覆盖。
- 暂停/取消/断线/过期连接/扫描期间变化均不投缺失票；完整覆盖两次才标记缺失，默认不删除资产或STRM。恢复从根重新校准，不接续过期覆盖。
- 批次共享新建目录只复用该批次已核对并保存的目录身份，不仅按路径认领其他目录。每项执行前检查文件、权限、连接和目标占用；禁止覆盖。
- 通知复用独立Outbox和投递重试/去重；管理日志显示原路径和批准结果，不收集登录请求正文。生产日志和凭据不得进入公共GitHub/Actions附件。
- 唯一docker-compose.yml仍只有app、PostgreSQL、Redis；不增加功能容器。

## 验收范围

隔离文件系统、PG/Redis及gRPC/HTTP提供方测试覆盖恢复/冲突/权限/修订/覆盖围栏；桌面与390px E2E验证工作台和真正隔离的批次文件操作。服务器验收只读浏览、已有STRM保持及302/CDN短Range链路。

真实媒体批量整理、真实PT下载→上传→完整入库，以及播放器完整音视频解码，均需另行选定合法样本并明确批准，不能由fixture或短Range结果代替。
