## 分页清单

SQL 当前页 + 总数：任务、日志（明示最多 20,000 条窗口）、下载、手动下载、上传、订阅、订阅运行历史、通知、媒体用户、扫描/目录覆盖、候选文件、受管资产/STRM、整理历史、归档、文件浏览、播放器观察/访问事件、在线会话、媒体用户活动、预处理任务、搜索记录、搜索结果、缓存、媒体目录/剧集子级。

发现服务及现有插件实例/工作流/运行历史接口只提供 hasNext 或固定边界，不假造总数，统一显示“总数未提供”并禁用无法证明的末页。站点账号按要求全页行式展示；内置目录有限集合沿用其总数。

页码使用独立列表 URL query 键，支持重新加载与后退；筛选值在翻页时保留。固定条数的接口明确显示每页条数，日志支持 50/100/200 选择。

## 克制的取舍

- 小型通用表单控件及 CSS 改为首包就绪，避免异步控件把标签行突然撑高 44px；表格、弹窗和日期选择等重组件继续懒加载。首入口 gzip 从约 114 KiB 增至约 151 KiB，没有增加依赖。
- 首次占位使用有界工作区/表单最小高度；不把队列重新放进内部滚动列表。空态插图缩至 80px，避免空态比加载占位高约 117px。
- 后台刷新及分页保留上一份成功数据。页面切换、表单保存冲突、身份切换仍遵守原有 fencing 与权限规则。
- 请求进度条 fixed 定位、短请求延迟显示；SSE 不被当成永不结束的普通请求。


## 审核修正与自查

- 账号行改为真实 favicon API，固定模板源、无账号 Cookie/Token、公共目标 DNS 固定、同源有限重定向，复用已有网络代理；Redis 正缓存 24 小时、负缓存 5 分钟。前端缺图保留固定 32×32 首字占位。
- 分享率绿色、积分橙色，上传/下载增加有语义的绿色 ↑ / 红色 ↓；标签与数值相邻，行高收紧，窄屏分组自然换行。
- 插件字段增加正式 title；有限配置值使用完整下拉选项，危险说明独立为提示，不丢弃。数字输入仍覆盖整个合法区间，修正两个增减按钮的半高布局和左对齐。配置成功不再显示技术性“回执”文案。
- 插件先在 `mediatool-plugin` 完成 race/vet、提交并推送 `e816bd75620d634b2c1635fee7dc335cbd5c1edf`，Actions 39874515737 通过，再 pin 与生成静态表单；没有改权限/资源声明，schema-only 权限守卫通过。
- 排查并修复未同步站点的 NULL metrics：过去一条未采集账号就能使全部站点指标返回 503；现在正常返回 200、指标 null 和“未同步”，不伪造零值。
- 统一北京时间，时间范围输入不再依赖浏览器所在时区；同页多列表分页拥有不同无障碍名称。
- 登录的首次状态检查先显示全屏有界占位，再显示已确认的登录/注册界面，避免误显账号模式。异步媒体详情抽屉已补桌面/窄屏 frame 检查。

## 保留的边界

APP_ENV 按业主要求暂缓，开发环境标识不隐藏。无上游总数的发现/插件列表不伪造总数；实例、工作流等现有接口的总数扩展仍是一个明确限制，末页按钮在无法证明末页时禁用。管理员原值日志、登录体不采集、恢复密码仅 stdout、STRM/302、既有账号权限和外部 Emby/CD2 均不改变。

补充边界：恢复/回滚与丢失回执核对依赖同一份有界聚合快照，备份、演练、维护单、告警、服务连接及 API 凭据/调用保留该接口供核验/选择使用，但列表 DOM 已统一为本地分页并把页码写入 URL；它们不是“每次只传当前页”的 SQL 列表。业务大列表采用 SQL 当前页。此取舍不改变已批准的恢复证明、凭据只显示一次和操作回读流程。

最终安全复查另外覆盖：字符串 source 原值不被快速日志索引丢弃；清空与快照失效在同一互斥边界；只恢复受限 0600 中断暂存文件；设置读取失败时停止保留清理并关闭 Debug，不能回退为更短的保留期限；旧的设置读取不能覆盖已确认保存，每批删除重新读取当前期限；仅修改保留天数不会偷偷延长正在开启的 Debug。
