# 播放器 UA 准入

UA 是客户端提供的标识，可伪造；准入策略不替代账号、媒体库权限或永久 STRM 凭据。
登录和浏览不会因名单限制被阻止，Emby PlaybackInfo、实际流/下载与既有 STRM 302 入口仍需通过准入。原生外挂字幕的 302 使用同一实际 UA；H3a 本程序上传字幕的小文本响应也受同一准入策略控制。

- **关闭**：不按名单限制，仍检查 UA 格式、身份和媒体权限，仍保留观测。
- **白名单**：仅允许匹配启用规则的 UA；空 UA 不匹配。启用前至少需要一条启用规则。
- **黑名单**：拒绝匹配启用规则的 UA，其余允许；空名单不拒绝任何合法 UA。

两份规则独立保存，共用一个修订号；切换模式仅改变模式，不移除规则。规则列表的“白名单规则／黑名单规则”选择与当前执行模式分开，可以预先维护未启用的名单。完整、前缀和包含匹配均区分大小写，不支持正则；宽泛匹配至少 3 字节。每份名单最多 128 条，精确规则优先于前缀和包含，命中规则 ID 可追溯。

观测同时显示两份名单的匹配状态。可从完整 UA 记录加入任一名单（默认完整匹配），核对后保存；该操作不会擅自切换执行模式。拒绝沿用原入口的 403 错误格式和相同文案，观测原因区分“未匹配白名单／命中黑名单”。修改冲突必须重新核对修订，不能盲目重试。

## schema 81

升级时，旧 `enabled=true` 映射 `whitelist`，否则映射 `off`；所有现存规则归入白名单，黑名单初始为空。原有规则 ID、策略修订和其他凭据均保留；`enabled` 在新接口中为派生的“模式非关闭”标志，执行依据为 `mode`。PUT 省略某份规则时保留它，明确传空数组才清空。

生产回退应使用升级前镜像及验证过的对应备份。结构 Down 仅供隔离测试：旧结构不能表达黑名单和包含规则，会移除这些新格式规则；不能以此冒充无损业务回退。

媒体用户列表的“锁定”来自真实的一分钟用户级登录失败限流或账号到期，不把共享 IP 的限流误判成账号锁定。最近 IP 仅来自已核验的公网活动；无记录时明确显示为空，不推断所在地。摘要查询按当前页聚合，登录锁定按整页批量读取，不逐用户往返数据库。
