# Emby 客户端接入

[文档目录](../INDEX.md) · [播放说明](playback.md) · [媒体协议接口](../NATIVE_EMBY_SERVER.md)

## 选择接入方式

| 方式 | 管理位置 | 使用账号与地址 |
| --- | --- | --- |
| 本程序内置媒体服务 | 播放服务 → 服务设置、媒体用户 | 本程序创建的媒体用户；内置媒体服务公开地址 |
| 已有外部 Emby | 连接 → Emby | 外部 Emby 用户；按实际部署选择外部服务或网关地址 |

这两套用户和权限不互相替代，管理员账号不能作为媒体用户使用。媒体服务公开端口不能指向后台管理端口。

## 内置媒体服务

1. 在“设置 → 通用与访问”配置“内置媒体库域名”，或直接在 Compose 设置 `MEMBER_PUBLIC_URL`；确认反代转发到 `MEMBER_ADDR`。
2. 在“播放服务 → 服务设置”保存服务名称和启用状态。
3. 在“媒体用户”新建用户并明确授予库的可见、可播放等权限；完成必要改密。
4. 在支持 Emby 协议的播放器中添加服务器，填写上述公开地址和媒体用户账号。
5. 浏览目录并试播，查看在线会话和访问记录。播放经固定入口跳转到官方地址，不通过管理页面播放。

默认容器媒体端口为 8092；宿主端口以自己的 Compose 为准。服务提供媒体浏览、播放信息与进度等接口，不是完整的 Emby 管理服务器；不支持的 WebSocket、外挂字幕或管理能力按接口返回处理。

## 外部 Emby

1. 在“连接 → Emby”添加地址和访问密钥，保存并测试。
2. 让外部 Emby 能读取受管 STRM、NFO 和字幕；共享路径应与实际挂载一致，不移动或清空原有 Emby 配置。
3. 配置独立网关公开地址时，反代到对应网关端口，保留客户端 UA 和 Range。模板容器网关端口为 8091。
4. 用自己的外部 Emby 用户浏览和播放，必要时在连接页做网关诊断。

检查通过只表示对应连接或协议检查成功，仍需使用实际播放器核对。多集索引引用完整文件，不承诺每个条目定位到对应单集起点。
