# 播放与 302

[文档目录](../INDEX.md) · [连接](../guide/connections.md) · [文件与 STRM](../guide/files.md)

## 固定链接与播放链路

STRM 保存稳定的解析地址，而不是会过期的官方 CDN 地址。播放链路为：

**播放器 → 固定解析入口 → 获取当前官方地址 → 302 → 播放器直接访问 115**

解析入口按当前播放用户、文件授权、路径与来源核对。它保留文件原来的稳定链接，不用媒体网关地址替换 STRM 原文。HEAD 和 GET 返回无媒体正文的 302；本程序不作为媒体数据代理，不提供 HLS、转码或媒体中转降级。

## 实际播放器 UA

115 官方取链发送实际发起播放的播放器 UA，并在返回地址前使用相同 UA 和有界 Range 检查。临时地址与 UA 可能绑定，不能用浏览器或其他工具的 UA 生成地址后交给另一个播放器。

临时官方地址只用于当前播放请求，不写入 STRM、目录 DTO 或普通持久缓存，也不发给插件。官方取链失败会明确报错，不静默退回 CloudDrive2 取链或服务器代理。

## CloudDrive2 与 115 授权

CloudDrive2 负责文件访问、扫描和上传等能力；115 官方授权负责所需的官方文件信息与播放地址。使用自己开放平台应用的授权；刷新凭据由程序加密和成对保存。扫码完成不代表所有文件和播放器都已经验证。

## 客户端要求

播放器需要能跟随 302，并访问返回的 HTTPS 官方地址。字幕、音轨、编码、拖动和续播还受客户端自身能力与媒体文件影响。服务器响应 302 或诊断得到部分内容，并不等于播放器已经成功解码。

非连续多集文件按明确集号生成索引，各条目可引用同一个完整文件；播放从完整文件起点开始，不做自动切片、跳集或章节定位。不得把未声明的中间集显示为已覆盖。

## 常见问题

- **“已配置，待播放器验证”**：用实际设备和实际账号试播。
- **官方授权失效**：到“连接 → 115/CD2”核对自己的授权，不更换为他人的凭据。
- **UA 拒绝**：到“播放服务 → 播放器准入”核对实际 UA 与白名单。
- **旧地址或缺失 STRM**：在“文件 → STRM 工具”预览修复，不能直接覆盖手工文件或生成新授权绕过。
