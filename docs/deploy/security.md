# 账号、安全与密码恢复

[文档目录](../INDEX.md) · [设置](../guide/settings.md)

## 管理员登录

首次访问时注册唯一管理员；注册后公开注册关闭。用户名和密码规则以登录表单为准，新密码为 6–20 个字符，支持中文与空格，不自动去掉首尾空格。

管理员会话使用受保护的 Cookie。修改密码会撤销全部登录；退出会撤销当前会话。账号安全页只显示当前登录状态，不提供其他会话的完整列表。媒体用户不能用管理员凭据登录，反之亦然。

反代应使用自己的 HTTPS 地址，并在 `AUTH_ALLOWED_ORIGINS` 填写实际完整 Origin。“设置 → 通用与访问”只填写真实可信代理 IP/CIDR，不信任任意外部转发头。

## 忘记管理员密码

只有拥有部署主机和应用数据权限的所有者可以恢复：

1. 确认 Compose 的 `PASSWORD_RESET_FILE` 和它对应的持久化数据目录，默认容器路径为 `/data/password`。
2. 确认没有未处理的恢复标记。在对应目录创建**空的普通文件** `password`；不能是符号链接，不能被组或其他用户写入，且 app 用户必须能够处理该目录中的文件。
3. 重启 app，并在自己的终端读取启动标准输出。默认路径可用下列命令创建标记：

```sh
docker compose exec app sh -c 'umask 077; set -C; : > /data/password'
docker compose restart app
docker compose logs --since 2m app
```

只在确实使用默认路径且没有已有标记时使用示例。自定义路径应按实际配置替换，不覆盖已有文件。

4. 使用启动输出中的临时密码登录，在 **30 分钟**内完成改密。临时密码只输出一次，不能在网页登录页、日志查看器、API 或标记文件中重新读取。

恢复会撤销已有会话并要求改密，但不重新开放注册，不删除 115 授权、站点凭据、媒体或其他服务。若输出丢失或状态未知，先检查私有标记和启动状态，不随意删除处理中的标记；确需重新恢复时由所有者核对后操作。

## 密钥与凭据

- 不借用其他应用或项目的 AppID、授权、Cookie 或 Token。
- 连接凭据默认隐藏，主动显示后及时隐藏；浏览器关闭编辑窗口不会保存未提交秘密。
- 外部 API 新凭据仅创建时显示一次，按最小权限创建并在不需要时撤销。
- 初始化后的 Compose、主密钥、备份、原始日志和数据库均属私有资料，不提交到公共仓库。
