# 日志与数据查看

[文档目录](../INDEX.md) · [运维页面](../guide/ops.md)

## 日志

在“运维 → 日志”按等级、模块、插件实例、关键词和时间筛选；分页查看并打开“完整原始记录”。可复制原始记录、完整请求地址或跳转地址，必要时下载原始日志。复制失败会提供手动选择内容。

管理员日志显示原始值和完整请求/302 跳转 URL，不自动打码，也不因为 URL 出现在详情里而请求媒体。

“日志设置”修改运行时级别；默认级别和文件位置由 Compose 配置。“清理日志”需要确认；清理后不能恢复已经删除的日志。容量限制、轮转和查询上限可能使更早记录不可用，不能把截断理解为没有发生过。

## 数据浏览

在“运维 → 数据浏览”选择 PostgreSQL 表或 Redis，使用分页、键筛选、详情和“复制当前页”。界面只读，不提供任意 SQL、更新或删除。

内容保留原值，包括密码哈希、密文和完整 URL。读取授权与管理员会话绑定，不把数据库凭据发给浏览器。

## 保密范围

- 只在受控管理环境查看；不要公开截图、粘贴原始数据或上传到公共构建产物。
- 不额外采集登录请求正文、Authorization/Cookie 头和密码恢复输出。
- 所有者恢复密码只出现在启动标准输出，不在网页日志查看器中，也不能从应用日志下载恢复。
- 主密钥不由后台导出；数据库备份也不能代替主密钥保管。
