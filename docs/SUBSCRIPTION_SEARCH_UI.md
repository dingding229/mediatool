# 搜索和订阅更新（0.15.0-dev / schema37）

- PT卡片动作列统一宽度/外边距，手机换行；最近搜索标题/状态/按钮固定列对齐。
- “大小”“做种人数”表头可点击或键盘切换升/降序。远程完整快照排序后分页，改变排序回第一页，原下载快照身份不变。
- 来源显示为WEB-DL、WEBRip、Blu-ray、Remux、HDTV；内部标准化键仍为web-dl/webrip/bluray/remux/hdtv，兼容发布标题常见大小写，避免显示名破坏匹配。
- 订阅TMDB查询行类型/关键词/按钮明确分列，移动端两行；空查询禁用。结果明确显示Redis缓存命中与有效期。
- 删除订阅体积/做种人数限制。schema37清零已有订阅这三项限制并使用全局间隔，递增修订使旧评估失效；媒体身份、启用状态、覆盖、既有下载不变。备份恢复校验单独校验授权转换，其余字段严格校验，不因必要转换放弃全表保护。
- 系统设置统一订阅间隔，默认30分钟，范围5分钟～1天；保存后更新已有订阅间隔和下次时间，但不启用停用记录。
- 包含/排除关键词支持Go RE2正则，每行一条，支持量词逗号。新订阅默认正则，旧订阅维持普通文字模式，可切换。正则默认区分大小写，可用(?i)忽略；非法表达式拒绝保存/匹配，不绕过身份/免费/H&R限制。站点搜索词仍是普通文字，正则仅本地过滤。
- TMDB媒体搜索、订阅查询、下载确认复用同一Redis搜索缓存。系统设置TMDB有效期（0禁用，最长30天）；配置/语言/修订隔离，失败不缓存，历史数据不因TTL改变删除。

官方Compose仍只有app/PostgreSQL/Redis；保护115授权、账号、媒体、原始STRM和外部Emby/CD2。真实播放器和各站点挑战验收仍独立于合成回归。
