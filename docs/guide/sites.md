# 站点

入口：`/sites`。标签：**站点账号 · 站点模板**。

## 选择站点模板

1. 打开“站点模板”，在内置目录选择所需站点。
2. 查看模板详情，点击页头“加载所选模板”。支持网格和列表查看。
3. 标记“使用中”的模板不能移除，已有账号需要的定义会保留。

模板来自程序固定依赖的内置定义，只在管理员选择后加载。页面不接受源仓库、提交、版本选择、URL 或上传安装，不会自动载入整个目录。更换定义不会清空账号凭据。

## 添加账号

1. 在“站点账号”点击“添加站点账号”，选择模板。
2. 填写表单要求的 Cookie、用户信息、浏览器 UA、订阅地址等。
3. 点击“验证并保存”；保存前检查站点登录。已有账号可通过“编辑账号”调整。
4. 用“更多站点操作”中的启停、采集或删除等可用操作管理账号。删除需要确认。

凭据默认隐藏，支持时可主动显示、隐藏、复制；关闭窗口后清空显示内容。账号和 RSS 是否可用以实际验证结果为准，不使用别人的 Cookie 或授权。

## 指标和采集计划

“数据与趋势”查看上传、下载、分享率、做种、积分等实际返回数据。使用“采集启用站点”或单站采集；“编辑采集计划”设置启用状态和时间，再“保存采集计划”。普通视图显示“每 2 小时”等可读说明。

未知指标显示“—”，不能据此当作零。计划停用不删除账号和历史指标；返回已排队时需要继续核对采集结果。
