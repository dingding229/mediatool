# 统一界面操作

[文档目录](../INDEX.md)

## 导航与标签

侧栏分为首页、获取、媒体、系统，共 13 个主页面。标签会同步到地址中的 `tab`，可以保存地址，或使用浏览器前进、后退。按 Ctrl/⌘K 打开快速前往，可输入页面或标签名称。

## 刷新、筛选与分页

- 页头右侧圆形箭头为“刷新”，只重新读取状态，不重新执行任务。
- 下载器同步、测试连接、开始扫描等是单独的业务操作，不会因为刷新页面而自动执行。
- 分页统一为“上一页 / 第 N 页 / 下一页”。“本页”数量不是全库总数；来源没有提供总数时不会推算。
- 备份功能、媒体来源等子分区以分段控件切换；主页面标签与子分区不是同一层级。

## 看懂状态

| 显示 | 含义 | 建议 |
| --- | --- | --- |
| 暂无记录 | 请求可用，但当前没有符合条件的数据 | 调整筛选或添加内容 |
| 读取失败 | 服务或网络发生错误 | 查看原因后重试读取 |
| 不支持 | 来源没有提供所需能力 | 使用该来源实际提供的功能 |
| 需要授权 / 无权限 | 尚未授权或当前账号不能访问 | 核对账号、连接与授权范围 |

“—”表示没有取得数据，不代表数值为零。

## 已排队和结果核对

- “已排队”只表示请求受理，不能当作下载、上传、整理、通知送达或恢复完成。
- 网络中断后，操作可能已经受理。使用“核对结果”或原有记录查看进度，不盲目新建相同任务。
- 配置提示冲突时，你的草稿会保留。先对照最新值，再选择采用新修订；不会自动替你保存。

## 危险操作

文件修改、批量整理、恢复、归档清理等按页面要求预览范围，确认后执行，再核验结果。需要输入确认短语时，必须与提示一致。

“归档订阅”不会删除下载、文件或运行历史；“删除文件（可恢复）”移到回收目录；“清理本地与种子”可能同时移除下载器任务和本地文件。请以确认框列出的实际范围为准。

## 配置与隐私

密钥默认隐藏。支持主动查看的字段可使用“显示 / 隐藏 / 复制”；关闭或保存后隐藏。复制失败时手动选择字段复制。登录密码不能回显。日志和数据浏览仅供管理员，可能含私有原始值，不要公开分享。
