# 搜索

入口：`/search`。标签：**搜索 · 搜索历史 · 发现推荐**。

## 搜索作品与资源

1. 在“搜索”填写 TMDB 媒体名称，按需设置类型和年份，点击“搜索媒体”。
2. 选择正确作品，查看简介和媒体身份；选择参与搜索的站点。
3. 点击“搜索站点资源”，进入搜索结果页。也可使用“站点直搜”输入关键词；下载前仍需确认对应影视身份。
4. 在结果页查看站点覆盖、促销、做种人数、资源大小和错误提示，按需要筛选与排序。
5. 点击“确认并下载”，核对影视身份、资源年份和 H&R 要求，再点击“创建下载任务”。

结果页地址为 `/search/results/:id`，可刷新或从历史继续打开。只有站点返回的有效部分结果时，会明确显示覆盖范围，不承诺已搜完所有分页。

## 搜索历史

在“搜索历史”查看缓存内容和有效期、打开原结果。历史查看不清理缓存；清理进入“运维 → 缓存”，有效期进入“设置 → 搜索订阅”。

## 发现推荐

切换“发现 / 推荐”，按页浏览已启用插件提供的作品。卡片显示插件名称，点击“搜索资源”带入作品身份，不会直接创建下载任务。作品详情按实际返回显示。

## 注意事项

- 创建下载返回“已排队”不代表下载器已接收或下载已完成。
- 投递结果未知时先核对下载任务；不要重复点击或更换资源重新投递。
- H&R 资源需要满足站点做种要求；识别到同一资源不代表已经满足清理条件。
- 没有站点、站点未授权或单站失败时，按提示在“站点”核对账号。
