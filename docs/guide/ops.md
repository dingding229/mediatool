# 运维

入口：`/ops`。标签：**任务队列 · 备份与告警 · 日志 · 数据浏览 · 缓存**。

## 任务队列

查看数据库、缓存、执行器和队列状态，按状态、队列、类型、关键词筛选任务。“任务详情”包含执行信息，内部标识在技术详情。需要重试失败业务时，沿“前往业务页核对”进入其归属页；任务页不盲目重放业务。可用“运行系统检查”创建检查任务。

## 备份与告警

分段切换“备份管理 / 恢复与回滚 / 运维告警 / 运行趋势 / 维护策略”。

- “创建系统备份”后核对结果；可查看详情、下载备份、固定备份、恢复演练或按条件删除。
- 恢复和回滚需要先预览、输入确认短语、审批，再由部署所有者执行页面提供的命令；审批不立即执行。
- 执行完成后仍要“执行后核验”，核对业务再解除维护。
- “确认告警”只确认你已经看到告警，**确认告警不等于问题已解决**。
- 维护策略包括备份、采样、保留与告警阈值，保存前核对草稿和修订。

详细步骤及备份范围见[备份与恢复](../deploy/backup.md)。

## 日志与数据浏览

“日志”支持级别、模块、实例、时间、关键词、分页、详情、复制和原始日志下载；清理需确认。“日志设置”修改运行时级别。

“数据浏览”只读查看 PostgreSQL 表和 Redis 键值，不提供执行语句或删除入口。管理员会看到原始值和完整请求/跳转地址，不自动打码。请勿公开日志或数据库内容，详见[日志与数据](../deploy/logs-data.md)。

## 缓存

切换 TMDB 或搜索缓存，查看详情、删除单项或清理此类缓存。清理需确认，结果未知先核对；有效期在“设置 → 搜索订阅”修改。搜索历史只有查看入口，不重复提供清理操作。
