# 运维

入口：`/ops`。标签：**任务队列 · 备份与告警 · 日志 · 数据浏览 · 缓存**。

## 任务队列

查看数据库、缓存、后台任务服务和队列状态，使用下拉框按状态、队列、类型、关键词筛选任务。“任务详情”包含执行信息，内部标识在技术详情。需要重试失败业务时，沿“前往业务页核对”进入其归属页；任务页不盲目重放业务。可用“运行系统检查”创建检查任务。

## 备份与告警

分段切换“备份管理 / 恢复与回滚 / 运维告警 / 运行趋势 / 维护策略”。

- “创建系统备份”后核对结果；可查看详情、下载备份、固定备份、恢复演练或按条件删除。
- 网页数据恢复可预览确认后直接排队；旧审批维护单和镜像回滚仍由部署所有者执行，审批本身不立即执行。
- 数据恢复完成后重新登录核对业务；镜像回滚仍要“执行后核验”，核对后显式解除维护。
- “确认告警”只确认你已经看到告警，**确认告警不等于问题已解决**。
- 维护策略包括备份、采样、保留与告警阈值，保存前核对草稿和修订。

详细步骤及备份范围见[备份与恢复](../deploy/backup.md)。

## 日志与数据浏览

“日志”支持级别、模块、实例、时间、关键词、分页、详情、复制和原始日志下载；清理需确认。“日志设置”修改运行时级别。

“数据浏览”只读查看 PostgreSQL 表和 Redis 键值，不提供执行语句或删除入口。管理员会看到原始值和完整请求/跳转地址，不自动打码。请勿公开日志或数据库内容，详见[日志与数据](../deploy/logs-data.md)。

## 缓存

切换 TMDB 或搜索缓存，查看详情、删除单项或清理此类缓存。清理需确认，结果未知先核对；有效期在“设置 → 搜索订阅”修改。搜索历史只有查看入口，不重复提供清理操作。

## 后台任务取消与核对后重试

任务队列中的“取消后台任务”停止本程序后续调度；执行中的任务需要协作退出，不能保证撤回已发生的外部操作。界面显示“已排队/等待核对”不代表取消或任务已完成。

“核对后重试”先检查原业务目标。已完成则收敛，确认未完成才排队；核对失败保持状态未知并显示原因，不能盲目重放。下载/上传、扫描和STRM修复仍在各自页面跟进；文件整理剩余项要重新预览批准，宿主维护沿原维护单核验，归档物理删除无法撤回。原业务控制入口保留。

### 网页恢复与恢复前回滚

“恢复与回滚”中的“网页备份恢复”可直接排队恢复，不必执行宿主命令。先核对备份来源、时间、
数据结构、大小与SHA256，再点预览；预览成功后按提示输入完整确认短语。需10分钟内重新登录。
系统先保留恢复前快照，失败不恢复；执行失败自动回滚。202仅表示排队，最终以执行记录为准。
成功后重新登录检查业务；旧任务不会自动重放。执行记录中可以预览并确认回滚到恢复前。
结果未知只点“核对中断结果”，不要再次提交恢复。恢复期间业务写入暂停；账号和115授权也随备份回退；
主密钥、磁盘媒体和现存播放文件不会被覆盖。完整范围见[备份与恢复](../deploy/backup.md)。

## 网页恢复：全部业务数据回到备份

在“备份与告警 → 恢复与回滚”先预览。账号密码、115授权、连接/设置、媒体/云盘索引/STRM记录、插件配置与KV都会回退，不再因它们与当前不同拒绝。逐表核对当前/备份行数，行数相同也可能内容不同。

确认短语与新近登录要求不变；先建恢复前快照，失败中止，恢复失败自动补偿。只补缺失且摘要正确的受管输出，不删除/覆盖现存媒体、STRM或下载目录，不动master key和Emby/CD2数据。恢复后请使用备份时的账号密码重新登录，进入同一页面查询持久化结果，不要因401重复执行。“回滚到恢复前”也要再次预览确认。

CLI与网页使用同一app执行器；精确保留账本、运行态安全归一化、命令和损坏边界见[备份与恢复](../deploy/backup.md)。
