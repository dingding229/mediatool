# 入库整理

入口：`/organize`。标签：**待确认 · 扫描 · 已入库 · 整理历史 · 恢复与归档**。

## 待确认

选择仍在库的候选文件，核对识别结果、作品、季和实际覆盖集号。使用“确认作品”或“批量确认作品”进入确认；筛选“需要确认或继续处理”可包含需要恢复输出的文件。需要更正时点击“查询TMDB”，选择正确作品；可使用“预览单集信息”。按提示确认入库，不确认未知或缺失文件。每次最多选择 20 项。

单集资料来自明确的作品、季号和集号。多集文件只按实际覆盖生成条目，不补猜中间集；不同条目可以指向同一个完整文件，播放不会自动切到某一集。

## 扫描

1. 选择目录并点击“预览扫描范围”。
2. 核对范围和限制，点击“确认范围并开始扫描”，完成确认。
3. “已排队”后查看扫描进度与目录记录。结果未知时点击“核对已受理扫描”，不重复创建。
4. 可按状态暂停、取消或重新完整对账；新增定时扫描默认不开启，保存前核对范围和计划。

扫描中断不意味着未看到的文件已经缺失。完整对账及文件变化监测以来源实际能力为准；变化提示不能替代完整扫描。

## 已入库与整理历史

查看资产、输出、STRM、重命名和步骤详情。身份或季集修正先预览影响；涉及输出位置变化时明确确认，已有文件、播放链接和共享资料受保护。物理批量整理进入“文件 → 文件浏览”。

“整理历史”可按阶段和条件筛选，查看步骤与原始技术详情。未知结果的批次先核对，移除历史不删除媒体或恢复信息。

## 恢复与归档

- 输出恢复：读取原上传的恢复预览，核对已有云端文件、输出布局和绑定，再明确恢复入库；不重新上传媒体，不重新猜测作品。
- 缺失 STRM 的修复进入“文件 → STRM 工具”。
- 归档管理：选择符合清理条件的归档，先预览，再输入所需确认短语。批准后核对记录，结果未知不更换请求重复执行。
- 保留期保存与归档物理清理不同；物理清理不可作为普通刷新操作。

恢复不会覆盖手工修改的文件或重建已经撤销的播放授权。遇到冲突时，先处理具体冲突再重新预览。
