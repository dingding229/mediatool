# 插件

入口：`/plugins`。标签：**已安装 · 插件目录**；每个实例有详情和独立的插件页面。

## 安装与启用

1. 在“插件目录”选择内置插件，点击“安装插件”。
2. 阅读所申请的权限和范围，明确同意后确认安装。安装完成仍为停用状态。
3. 在“已安装”点击“管理插件”，填写配置并保存。
4. 确认用途和权限后明确启用。一个定义可以创建多个独立实例，但各自配置和数据不共享。

只能选择随程序提供的内置定义，不支持 URL、源代码、压缩包或二进制上传安装，也没有来源、提交、版本选择器。

## 实例详情

可查看状态、权限、配置、实例数据、服务与命令、数据快照及日志。停用时可保存 JSON 配置；动态表单、插件页面和仪表盘需要对应插件已启用，不会为了显示界面自动启动插件。

“工作流管理”提供有界的手动工作流；工具测试只由管理员人工调用。会修改数据的操作需再次确认，不会自动进行对话或无人值守工具循环。

## 权限变化和不可用状态

- 定义扩大权限后，实例会停止，页面展示新增或变化的权限；管理员确认权限后仍需明确启用。
- 定义不再提供时，显示“不可用”，配置和数据保留，不能启用或创建分身。
- 安装、卸载或调用结果未知时，先核对原实例、操作和运行记录，不重复新建实例或更换操作标识重试。
- 不需要的实例可以按确认范围卸载；不要把卸载插件当作撤销已经产生的外部业务操作。

完整能力与作者接口见[插件说明](../PLUGINS.md)。

## 内容更新与只读状态

应用发版但插件内容未变时，不增加插件定义修订，也不再次请求授权。
插件定义、权限、SDK/处理器源码或捆绑界面内容变化才改变内容指纹；旧构建指纹在已锁定源码内容可证明等价时自动重绑，不清除配置、KV 或数据。
权限待确认、停用或调用缺少写权限时，错误会明确说明原因，并提示到插件页确认权限或启用后重试。
站点受控请求仅提供有界、去凭据的文本响应和少量响应头，`truncated=true` 表示不是完整正文；二进制和原始凭据响应不开放。
