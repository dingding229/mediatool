# 播放服务

入口：`/playback`。标签：**服务设置 · 媒体用户 · 播放器准入 · 在线会话 · 预处理**。


可播放视频容器统一使用[下载入库的视频清单](downloads.md#上传入库)，匹配不区分大小写。`iso` 不进入视频入库/STRM 播放链路：ffmpeg/Lavf 不能通过 HTTP 302 直接解析光盘镜像。保持原 STRM 固定解析链接、按实际播放器 UA 获取 115 临时链接、302 直达官方 CDN，不增加中转、HLS 或转码。

## 服务设置

填写内置媒体服务名称和启用状态，点击“保存服务设置”。查看目录与服务能力；配置冲突时对照最新值后再保存。

播放链路：**播放器 → 固定解析入口 → 302 → 115 官方地址**。服务器不中转流量。客户端连接方式见[内置媒体客户端接入](../NATIVE_EMBY_SERVER.md)。

## 媒体用户

点击“新建媒体用户”，输入账号、显示名和密码，配置库的可见/可播放/可下载权限、同时播放数等。新用户不自动获得全部库权限。

使用“编辑用户”“设备与历史”和“更多”管理账号、查看活动、重置密码或删除。密码由管理员在表单输入，不回显已有密码；强制修改密码的用户需完成改密才能正常登录播放器。

## 播放器准入

播放器标识（UA）用于识别应用或设备。默认可以只记录访问；“加入白名单”或“添加 UA 规则”后，仍需明确启用限制才开始按规则拦截。

可筛选访问汇总和访问明细，查看实际 UA 和来源地址。“删除规则”和“清空访问记录”需要确认。可信反代设置在“设置 → 通用与访问”。

## 在线会话

查看会话及详情，按页面提示管理用户登录。“撤销该用户全部登录”影响该用户所有设备与播放，不是只结束列表中一行。界面没有单独结束一个播放会话的服务端能力，不应把撤销全部登录当作单会话操作。单设备撤销在“媒体用户 → 设备与历史”。

## 预处理

播放服务总开关只在“服务设置”修改；“预处理”显示当前状态并提供“管理播放服务开关”链接。保存探测、截图相关设置，查看任务与缓存状态。探测和截图是后台处理，不参与实时媒体转发。任务失败时先核对记录，再使用允许的重试；结果未知不能直接重复执行。清理截图缓存需要确认。
