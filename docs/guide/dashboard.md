# 首页

入口：`/dashboard`。服务就绪状态、需要处理的事项、首次配置引导、链路计数、服务器状态、最近搜索和插件仪表盘集中在这里。

## 常用操作

1. 先查看 115、CloudDrive2、STRM、Emby 四张卡片。状态正常时用“查看”，异常时用“去处理”进入对应连接标签。
2. 全部正常时，“待处理”只显示“暂无待处理事项”；有内容或读取出错的分组才显示。在其中查看失败任务、待确认识别、上传和批次核对、未确认告警、插件权限事项，点击进入负责处理的页面。
3. 按引导完成连接 115/CD2、关联 Emby、添加站点、设置分类规则。全部完成后可以收起；在“设置 → 账号安全”使用“重新打开配置引导”恢复显示。
4. 使用页头“刷新”读取状态；最近搜索中同一关键词只显示最近一次，链接继续打开那次结果。

## 注意事项

- “检测有效”是最近一次检测仍有效，不代表所有播放器都已试播成功。
- STRM 显示“已配置，待播放器验证”时，应在播放器试播，不能当作播放已经验证。
- 一个分组读取失败不影响其他分组，错误不等于没有记录。
- 告警确认在“运维 → 备份与告警”完成；确认不代表故障已经解决。
- 插件仪表盘只来自已启用的内置插件，不加载远程代码。

手机端四项服务状态使用紧凑列表；链路中的“媒体文件”按文件数量统计，不等同于媒体库按作品分组的数量。

## 失败任务与原因

失败任务标题显示任务类型，以及能够查到的站点或对象名称。相同任务类型、对象和原始原因会合并，展示次数与最近发生时间。次数统计来自最近读取的最多 100 条失败记录，不等于完整 24 小时总量；记录超过读取范围时会提示去运维页查看更多。

常见网络、登录、权限、空间等错误在首页用中文解释；未知错误保留原文。站点类“去处理”进入对应站点账号，其他失败进入“运维 → 任务队列”并筛选到原任务。原始错误仍可在任务详情、日志和数据浏览中查看。

## 连接配置与检测

“需要检测”表示连接已经配置，但没有有效检测记录或记录已过期，不表示未配置。配置引导显示“已连接，需要检测”。检测记录会在保存并验证、手动测试及 115 授权后的验证中更新，超过 24 小时需要重新检测；程序没有定时自动续期检测记录。

115 卡片提供“立即检测”。同步返回的明确结果会更新状态；“已排队”不代表检测通过。结果未知或刷新页面后有未确认检测时，先使用“核对结果”，不会重复发送测试。检测通过也不代表播放器已经试播成功。
