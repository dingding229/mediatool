# 媒体库

入口：`/library`。这是**只读展示页**，默认来源为“内置媒体库”，可切换“Emby”。

## 浏览作品

1. 根据标题和类型筛选，使用“上一页 / 下一页”浏览海报墙。
2. 点击作品打开详情，查看海报、简介、年份、评分、类型、文件大小、清晰度等已返回信息。
3. 剧集可按季、集逐层浏览；第 0 季也可保留。Emby 首页与“全部媒体”可以切换。
4. 内置媒体有可用链接时，详情提供次要操作“复制播放链接”。复制失败时手动选择链接。

## 注意事项

- 页面没有添加、删除、修复、连接配置或其他管理操作，也不提供网页播放。
- Emby 未连接时会说明状态；需要使用它时，在“连接 → Emby”配置。
- 内置列表依据已入库文件分组，作品数量明确区分本页范围；季集只展示当前读取到的内容，不承诺整部已收齐。
- 没有返回评分、大小或清晰度时显示“—”，不是零分或空文件。
- 复制的是已有稳定播放链接，不是临时 CDN 地址；实际播放仍由播放器完成。
