# 媒体库

入口：`/library`。这是**只读展示页**，默认来源为“内置媒体库”。

## 浏览作品

1. 根据标题和类型筛选，使用“上一页 / 下一页”浏览海报墙。
2. 点击作品打开详情，查看海报、简介、年份、评分、类型、文件大小、清晰度等已返回信息。
3. 剧集可按季、集逐层浏览；第 0 季也可保留。
4. 详情显示已持久化评分、文件大小和探测清晰度；类型使用目录分类。管理端不再提供获取或复制播放链接入口，播放器与 STRM 解析链路不受影响。

## 注意事项

- 页面没有添加、删除、修复、连接配置或其他管理操作，也不提供网页播放。
- 内置列表按已入库作品聚合，点击剧集先读取完整季列表，再进入季内集列表；各层独立分页，并按季号/集号排序。作品数量不再是当前文件页的分组数量，仍不承诺整部已收齐。
- 没有返回评分、大小或清晰度时显示“—”，不是零分或空文件。
- 复制的是已有稳定播放链接，不是临时 CDN 地址；实际播放仍由播放器完成。

## 外挂字幕边界

云盘扫描保留字幕索引（srt/ass/ssa/vtt/sub/idx/sup），不把字幕当视频入库。
内置媒体服务器关联同目录、与视频同名或以“视频名.”开头的字幕，可带 `.zh/.chs/.eng/.forced/.default/.sdh` 等后缀。
播放信息展示外挂字幕；客户端直接用原字幕格式，经鉴权和播放器 UA 准入后 302 到 115 官方临时地址。
需要转换格式、烧录或提取的客户端不支持；sub/idx/sup 等由客户端自身决定是否支持。


## 大片库浏览与缓存

搜索在 SQL 内先执行权限、分级和关键词过滤，再计算候选上限；超过五万匹配时明确提示范围过大，不把截断结果冒充完整结果。
片库缓存是可再生数据：单值最多 2 MiB、总 payload 最多 16 MiB / 64 项，短期过期且校验数据库写入 fence；扫描、整理、删除或权限变化后会重新读取，不依赖手动刷新权限缓存。
