# 下载

入口：`/downloads`。标签：**下载任务 · 上传入库 · 手动添加**。

## 下载任务

1. 查看任务状态、同步时间、进度、下载速度、做种和错误信息。
2. “刷新”只读取已有记录；“同步下载任务”主动从下载器更新状态。
3. 使用“更多”中的可用任务控制。按钮只在服务允许的阶段开放；需要确认时先阅读范围。
4. “清理本地与种子”必须确认做种要求、上传校验和入库情况，会影响本地文件与下载器任务。

不应把“暂停 / 恢复 / 删除”等所有下载器能力都视为可用按钮：管理界面只提供后端实际允许的控制，未开放的下载器操作需在下载器中完成。

## 上传入库

查看上传、哈希校验、处理阶段和需核对批次。使用“核对”检查远端会话；“上传控制”中按状态提供暂停、恢复、绑定已有会话、取消或确认后重试。

上传结果不明或远端会话缺失时，先核对已有任务和文件。明确需要重建时仍需单独确认，不会自动建立替代上传。输出需恢复时，沿页面文字链接进入“入库整理 → 恢复与归档”。

## 手动添加

1. 点击“添加种子”。
2. 选择“种子文件”或“种子链接”，提供自己的合法资源。
3. 核对后提交；手动添加只交给下载器，不自动识别、上传、入库或删除源文件。
4. 结果未知时先“核对下载器”；下载器同步入口在“下载任务”。

## 注意事项

- 实际零进度与尚未同步不同；未知进度不显示为 0%。同步失败保留最近有效进度并显示错误。
- 100% 传输不代表哈希校验、输出、Emby 可见性和播放均已完成。
- 不移动或自动删除做种源文件；清理需要独立确认。
