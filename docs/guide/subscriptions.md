# 订阅

入口：`/subscriptions`。标签：**订阅列表 · 运行记录**。

## 新建订阅

1. 点击“新建订阅”，选择准确的影视作品。
2. 选择站点与发现方式，填写筛选。可设置搜索词或正则、包含/排除词、大小、做种人数、免费限制、H&R 保护，以及分辨率、来源、编码等质量要求。
3. 剧集需要核对季度、实际集号和历史范围；不要把多集文件误认为单集。
4. 进入预演，点击“保存停用草稿并预演”。这会保存停用草稿，规则预演不会创建下载。
5. 查看预演决策和原因。确认后进入保存步骤，按需要勾选“保存后启用自动下载”，点击“保存订阅”。

## 跟进与调整

- 卡片保留“立即运行”和“编辑”。“更多”中有“运行记录”“预演”“启用 / 停用”“归档”。
- 点击影视名称查看订阅详情。运行记录展示每次结果、资源决策和原因，原始记录在技术详情。
- 使用订阅状态和名称筛选；已归档订阅仍可查看记录。

## 注意事项

- 新订阅默认停用。自动下载需要你明确启用；停用后不再自动下载。
- “立即运行”收到“已排队”不是运行成功。结果未知时先核对原运行，不重复执行。
- 归档保留下载、媒体文件和运行历史，不是物理删除。
- 配置修订冲突时，先刷新并核对新值，再重试保存；不要覆盖他人的修改。
