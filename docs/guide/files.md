# 文件

入口：`/files`。标签：**文件浏览 · STRM 目录 · STRM 工具**。

## 文件浏览

选择本地或云盘目录，用面包屑进入路径，按名称筛选。移动端每项显示名称、类型/大小和“更多”，不需要横向拖动表格。

- “新建文件夹”：输入名称，核对目标目录后确认。
- 单项“更多”：按权限提供重命名、移动、删除（可恢复）和影视整理。
- 批量整理：选择文件后点击批量整理预览，核对作品、实际集号、目标和名称，批准后再核验。
- “操作记录”：在抽屉查看已记录步骤，使用“查看步骤与核对”跟进原操作。

变更按**预览 → 核对 → 执行 → 核验**进行。预览过期或文件变化时需重做预览；响应丢失不能据此重新提交。删除（可恢复）会移入回收目录，不等于永久删除。受管输出、在途任务、越界路径和只读目录受到限制。

本地可见范围由 Compose 挂载及 `LOCAL_BROWSE_ROOTS` 决定，界面不能浏览宿主未挂载目录。

重命名不会转换文件格式：上述[视频扩展名清单](downloads.md#上传入库)以及 `iso` 均受到“改名不改扩展名”保护，省略扩展名时保留原扩展名；不能直接改成另一种媒体容器扩展名。ISO 的改名保护不表示支持播放或生成 STRM。

## STRM 目录

按受管输出路径浏览，查看资产与输出详情。使用“预览STRM内容”“读取原文”或“复制原始内容”；摘要和指纹在技术详情。复制失败时手动选择原文。

## STRM 工具

选择受管资产，检查缺失文件，预览修复范围并批准。修复只恢复可证明的原文，不覆盖手工文件、不重传媒体、不生成替代播放凭据。批准后核对已有修复请求。

播放链路诊断可生成固定链接、下载 STRM、诊断指定文件。**播放时直接跳转到 115 官方地址，服务器不中转流量。** 页面不提供媒体中转、HLS 或转码开关。
