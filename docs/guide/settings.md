# 设置

内容宽度和左边距与其他页面一致。按分区修改，每个分区单独保存。入口：`/settings`。标签：**通用与访问 · 命名与分类 · 搜索订阅 · 外部 API · 移动端 · 账号安全**。

## 通用与访问

编辑后台访问域名、播放链接域名、内置媒体库域名、Emby 网关域名，点击“保存域名设置”。输入预填实际生效值；未修改的默认值不会自动写回。留空字段按部署配置推导地址。

可信反代 IP/CIDR 在“访客地址识别”保存。只填写实际代理来源，否则访客地址可能被伪造；留空仅记录直接连接地址。域名、HTTPS、端口和反代路径需要与真实部署一致。

修改域名不会自动覆盖已有播放文件，需要时进入“文件 → STRM 工具”预览修复。TMDB 与代理在“连接 → TMDB/代理”，不在本页重复配置。

## 命名与分类

修改电影、剧集命名模板并查看实时预览；设置所需媒体资料生成和上传后清理。启用清理前必须确认影响，预览成功不等于已保存。

目录分类可添加、编辑、排序和启停分组与规则，按电影、电视剧、动漫、国家、语言、题材等组织。点击“应用到草稿”后仍需“保存目录分类”。没有匹配规则时按页面及预览说明处理，不用示例目录代替实际配置。

## 搜索订阅

设置搜索缓存、TMDB 缓存有效期和订阅调度。时间计划采用分、时、日、月、周五个字段，时区为 Asia/Shanghai。清理缓存进入“运维 → 缓存”。

## 外部 API

使用“创建 API 凭据”选择名称和权限。**新凭据只在创建成功时显示一次**，及时复制并私下保存；关闭后无法从列表恢复。列表支持撤销；“验证状态访问”用于验证当前输入的凭据，不把密钥存入浏览器持久存储。

## 移动端与账号安全

- “移动端”按浏览器实际能力显示安装、更新及独立窗口状态。
- “账号安全”显示当前管理员登录状态、修改密码和退出当前会话；不提供其他管理员会话的完整列表。修改密码会撤销全部会话。
- 使用“在首页显示配置引导”或“重新打开配置引导”控制引导显示，仅保存在当前浏览器。

每个表单独立保存，只提交有改动的配置分区。冲突或结果未知时保留草稿并读取最新配置，核对后继续，不自动覆盖或重复保存。

## 管理端登录会话

“账号安全”分页列出全部有效管理端登录：账号、创建/最后活动/到期时间、连接IP、原始UA及当前会话标记。可确认后撤销指定登录，下一次请求立即需要重新登录；撤销当前登录会跳转登录页并提示。此操作不影响媒体服务器用户会话。页面顶部的刷新仅重新读取，不撤销任何登录。

管理端登录会话的活动时间每分钟节流更新，IP或UA改变立即记录；UA最多512个UTF-8字节。活动记录暂时失败不会导致有效登录被拒绝；会话撤销仍在下一请求立即生效。
