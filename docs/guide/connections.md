# 连接

入口：`/connections`。标签：**115/CD2 · Emby · 下载器 · 通知渠道 · TMDB/代理**。

默认打开“115/CD2”，每个标签显示自己的连接状态。四项服务的整体状态在首页查看。

## 115/CD2

1. 添加 CloudDrive2 连接，填写地址、凭据和云盘根目录。
2. 添加 115 连接，使用自己的开放平台应用信息；可以先保存未授权配置。
3. 点击“115扫码授权”，扫描二维码并等待授权状态；离开或取消时不会自动另建授权。
4. 使用“测试连接”核对；按需查看云盘空间和会员信息。

CloudDrive2 提供文件浏览、扫描、上传等能力；115 官方授权用于按实际播放器 UA 获取播放地址。两者不是可互相替代的凭据。授权和保存不等于自动启用服务。

## Emby

添加外部 Emby 地址和访问密钥，保存并测试。网关诊断在这个标签；它检查连接与网关状态，不代表所有播放器都已试播成功。内置媒体服务在“播放服务”。

## 下载器

在此添加或编辑 qBittorrent 地址和凭据，点击“加密保存”，再按需要“测试连接”。下载页不重复提供配置表单，仅通过“管理下载器”文字链接进入这里。

## 通知渠道

添加或编辑实际支持的渠道，测试和保存流程以表单提供的能力为准；可查看投递记录和错误。没有独立的“测试发送消息”接口或按钮，不应把测试连接当作消息已送达。

## TMDB/代理

配置 TMDB Token 与网络代理。代理可分别用于 TMDB 和站点请求，失效会明确报错，不自动绕过安全设置。其他服务不会因这两个代理开关而改用代理。

## 密钥与冲突

密钥默认显示是否已设置；支持主动查看的字段旁可点击“显示”“隐藏”“复制”。主保存按钮在表单底部左侧，115 的“更多保存方式”还提供“保存并115扫码授权”。保存或关闭编辑窗口后隐藏；复制失败则手动选择。留空通常保留原值，清除必须明确选择。

配置已被修改时保留输入并显示对照，采用新修订后再保存。测试连接返回“已排队”不代表连接已验证；结果未知先核对，不重复创建连接或测试任务。
