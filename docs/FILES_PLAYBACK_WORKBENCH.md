## 播放访问

“播放器访问”增加访问IP列和逐次访问明细。每次保留UA、实际连接IP、Emby/STRM入口、时间、UA检查结果及最终HTTP状态，最多10000次。没有可验证Emby凭据时显示“未核验 / 不适用”；不使用UA/IP关联用户，不信任客户端UserId。只有调用者Token在Emby官方用户接口核验的ID/名称才能记录；请求被UA策略拒绝时不向上游取身份。后台仅管理员可读取，媒体账号无权查看。

反代未配置可信IP链时显示实际代理连接地址，不把任意X-Forwarded-For当真实客户端地址。STRM独立请求没有Emby身份，不能假定来自最近登录用户。新明细清理与UA聚合清理一起执行，不删除白名单。

## 资源获取

订阅当前/历史分类与表格间距24px；PT站点信息及右侧按钮垂直居中，移动端操作区独立。搜索“促销”列支持点击排序：下载系数从小到大/从大到小，未知始终在最后，排序覆盖整个冻结结果集，分页与下载资源ID保持稳定。

## 115账户

空间和会员信息通过现有115 OAuth授权直接调用115官方 `/open/user/info`。复用加密Token刷新与单次过期重试。显示授权账号ID、名称、来源及时间；空间不再调用或兜底到CloudDrive2。API未返回或格式不正确则明确未知，会员期限未返回不推断永久会员。CloudDrive2仍负责文件/目录管理，与官方账号不默认相同。

## 独立STRM页面

- `/strm`：“STRM目录”，仅列本程序具有归属证据的STRM资产，真实TMDB海报，查看原正文、Emby逐路径核验。
- `/strm-tools`：“STRM工具”，单文件链接预览/诊断/复制/下载，按行批量预览，以及批量检查与修复。
- 页面去掉NFO集合，**不删除已有NFO、刮削设置、归属、审计或恢复证据**。

## 批量修复

先选择托管资产（每批最多100份STRM），检查生成10分钟有效预览，显示完整/缺失可修复/冲突需人工核对。批准原批次和摘要后进入library队列，只恢复缺失文件：

1. 有加密原文且摘要及当前文件Key核验一致：按原始字节恢复。
2. 旧journal原文被擦除：使用现有文件级Key生成候选正文，只有与原归属SHA256完全一致才允许；不创建/旋转Key、不自动换域名。
3. 同摘要现存文件无需写；手工修改、符号链接、归属/修订变化、媒体不在库、Key撤销或无原文证据均跳过。
4. 恢复使用同目录临时文件同步及hard-link原子发布；目标若在检查后出现，拒绝覆盖。文件系统不支持此安全创建方式时失败关闭，不回退覆盖式写入。
5. 执行意图复用已注册的加密journal列，完成的STRM保留加密原文；NFO仍沿用既有处理。批次结果持久化，重载可继续查看；任务耗尽时需明确“核对后恢复此批次”，不会盲目重新创建任务。

现有文件修复不会修改源媒体/NFO或布局。改变已有固定链接、迁移域名、修改输出结构依然必须走独立明确预览/迁移流程，不属于自动缺失修复。

## 历史

新增阶段快捷入口、当前筛选总数/本页待处理计数、中文阶段状态、来源→目标分区和步骤卡片。完整JSON证据默认折叠。STRM修复批次纳入历史并链接至持久化批次；既有活动任务/未知结果的历史不能删除，结束记录移除仍仅隐藏列表，不删除审计/媒体。

## API

- `GET /api/v1/player-access/events?page&pageSize&q&observationId`：逐次访问。
- `GET /api/v1/cloud/accounts/info`：115官方账号信息；不依赖CD2空间。
- `GET /api/v1/library/outputs?kind=strm`：仅具有托管STRM的资产，附真实海报URL；不传kind仍保留通用归属证据接口。
- `POST /api/v1/strm/batch-preview`：`{paths:[...]}`，最多100，逐项有效/错误，仅生成链接。
- `POST /api/v1/strm/repairs/preview`：`{assetIds:[...]}`，持久化预览，不写文件。
- `GET /api/v1/strm/repairs/{id}`：当前状态/逐项证据。
- `POST /api/v1/strm/repairs/{id}/approve|retry`：`{digest,confirm:true}`，幂等批准/明确恢复。

所有管理接口保留管理员会话、Origin和CSRF检查。仅主程序、PG、Redis，无新容器或调度进程。测试只使用media_tool_test、Redis15和临时文件；生产验收不执行修复真实媒体。

服务器所有者可在已有app容器执行 `docker compose exec -T app /app/media-tool -role account-info` 只读查询同一官方账户，输出空间/会员/账号范围，不输出OAuth Token、不创建后台会话或恢复密码。仅当Access Token过期时沿用正常加密刷新；不调用CD2空间接口。该CLI供所有者验收及诊断，不是公开HTTP认证绕过入口。
