# 2026-10-12 工作台改版开发与发布计划

## 范围与执行顺序

1. **部署与安全基础**：仍为 app / PostgreSQL / Redis 三个容器，唯一 docker-compose.yml；取消 ${...} 和部署 .env 插值，参数直接编辑 Compose。公开仓库仅提供空密钥/示例参数，实际服务器 Compose 保留私密密钥，不提交生产配置。原业务卷和 STRM 保留。
2. **账号恢复**：删除后台恢复码界面/API。宿主映射的数据目录放置空 `password` 文件，重启应用触发随机临时密码，原子消费标记，仅在启动控制台输出一次；临时密码登录强制改密后才能访问普通管理 API。使用数据库事务、单例锁、文件类型/权限/身份检查和会话撤销。恢复临时密码不得出现在后台日志、文件管理、数据库详情中；不通过后台创建恢复文件，不替用户触发真实账号恢复。
3. **本地文件与命名**：自动提供应用数据和容器可见本地目录，无需手工绑定本地连接。宿主机未挂载目录无法读取，不挂载整个宿主根、不开放配置/恢复文件。电影、剧集模板独立保存于系统设置，预览默认使用全局模板；保留自定义名称。不自动批量改变实际媒体。增加 0day/Scene 文件名解析，识别电影/剧集、标题、年份、季集、分辨率、来源、编码和发布组；不确定解析明确提示，通过 TMDB 候选匹配而非盲目绑定。
4. **配置归属和添加验证**：PT 账号→PT 站点；Emby→媒体库；CloudDrive2/115→云盘；通知独立模块；下载器→下载与传输；TMDB→系统设置。服务连接仅汇总查看。连接在添加/修改保存流程自动验证；保留 115 无 Token 授权草稿，扫码授权时验证，不能要求授权之前通过媒体验证。取消手动测试按钮，不将无法联系的服务标为正常。
5. **媒体库首页**：以用户截图为结构参考：真实 Emby 分类横幅、正在播放、继续观看/近期观看、最新入库；保留本程序入库列表、分类进入和搜索。不硬编码示例海报/虚假媒体，不把 Emby Key 放进图片 URL。观看状态按选定 Emby 用户范围读取。
6. **日志和数据工具**：内置有界 JSON 日志文件及 stdout，debug/info/warn/error；后台增加日志级别筛选、大小、保留文件统计和明确确认后的清理。日志、数据库详情同样脱敏。PostgreSQL 显示发现的公共业务表、列类型、行数、分页格式化数据；Redis 显示 SCAN 分页、类型/TTL/大小和有界内容。只读、不提供任意 SQL 或命令、不开放数据库端口到公网。
7. **验证与发布**：新增单元/数据库集成/端到端测试，PG 修改测试串行，桌面/手机截图验收；检查密码恢复强制改密、标记单次消费、文件隔离、日志轮转/清理、数据只读脱敏、0day 歧义、模块入口及自动验证。GitHub 推送→Actions AMD64→Docker Hub→服务器拉取；先备份，核对原账号/115授权/输出/外部 Emby/CD2及其他容器不变，复测原 STRM 302→115 CDN。失败证据保留，不把真实播放器解码或长期稳定性标为通过。

## 实现边界

- 自动显示的是容器可访问目录，不能无挂载读取任意宿主文件；系统伪文件、密钥和服务私有数据受保护。
- 0day 标题解析是线索，不等于 TMDB 身份已确认；没有年份或仅数字标题不能猜造年份。
- 恢复密码打印仅发生在部署所有者明确创建空文件并重启时，常规日志脱敏不允许后台查询该密码。临时密码 6–20 字符、短期有效且强制更换。
- 实际密码和主密钥不进入公开 GitHub。应用参数在容器 environment 字段使用直接值，这是 Compose 内配置，不是外部环境变量插值。
