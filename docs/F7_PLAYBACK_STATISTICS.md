# 播放统计与公网 IP

管理员入口：播放服务 → 媒体用户 → 设备与历史 → 播放统计 / IP；全局 IP 汇总在播放服务 → IP 统计。保留天数在运维日志设置中，与日志保留天数相邻，默认 180 天（1–730 天）。

## 数据口径与生命周期

| 数据 | 原有语义 / 新语义 |
|---|---|
| `media_user_item_data` | 每用户/条目的最新续播与完成状态，仍用于原生媒体协议；原 `play_count` 是完成次数。 |
| `native_playback_sessions` | 播放准入槽与 Playing/Progress/Stopped 状态，未激活的 PlaybackInfo 草稿不算播放；无进度 5 分钟 stopped。 |
| `media_playback_events` | 每个实际播放会话 ID 一行；未看完也计一次；Progress/重试合并，302 只增加重定向次数。 |
| `duration_seconds` | 相邻有效进度增量与观测经过时间的较小值，单段最多 5 分钟；暂停、回退、无上报空档不虚构时长。 |
| `media_playback_ips` | 每播放会话/公网 IP 一行，首次与最近出现时间；按 IP 汇总使用不同事件、设备、用户的 distinct 数。 |
| `media_device_ips` | 每设备/公网 IP 一行，统计成功鉴权请求，含登录/浏览；与播放次数分开标注。 |

统计从启用时开始，不反推旧的按条目历史。保留期也限制“全部”。媒体用户删除在既有删除事务内经外键 `ON DELETE CASCADE` 删除事件、IP、设备；停用或撤销库权限保留历史。清理每分钟检查，每次最多删除 1000 行，外键同步移除事件 IP。所有统计快照经过有界队列，丢弃/写入失败仅固定文案日志，不影响 302；不采集 Token、Cookie、STRM/CDN URL。HEAD 预检不记播放。

## IP 信任边界与范围清单

统一组件为 `internal/platform/clientip`。从 TCP 对端起，只在对端属于已配置可信 CIDR 时读取 XFF（无 XFF 时使用 X-Real-IP）。由右向左止于首个不可信节点；若它非公网，不能跨过该节点去选择客户端可伪造的左侧公网 IP。排除私网、回环、链路本地、CGNAT、文档、多播/保留段及非公网 IPv6；无公网证据存空值，显示“局域网/保留地址”。历史私网不迁移/删除，只在展示时隐藏。

| 范围 | 采集 / 展示 |
|---|---|
| 管理员登录、会话、失败限流 | 统一可信链，保存公网地址；管理会话使用 `IpAddress`。 |
| 媒体鉴权、设备与会话 | 统一可信链，last_ip 与异步设备 IP 记录；IP 通过管理端展示。 |
| 播放上报、302 | 服务器确认的用户/设备/条目，统一 IP；异步事件、IP 记录。 |
| 播放器准入、外部 token 访问 | 共用管理 listener 的地址证据与准入记录；旧 IP 展示同样过滤。 |
| 请求日志 | 新的结构化 clientIp 仅公网；归属地按当前库在显示层查询，不改写原日志。管理员复制原记录功能保留原值。 |
| 告警 / 通知 | 当前无独立 IP 采集字段或通知模板；不另造 IP 数据。 |
| 插件 Host | 当前媒体/准入 DTO 明确不提供 IP/UA；保留该隔离，不扩大插件权限。 |
| 播放解析缓存 | 只使用统一公网地址参与现有缓存键；302 和 STRM 原文不变。 |

## ip2region 离线数据库（H2a）

官方 Go 绑定固定为 `github.com/lionsoul2014/ip2region/binding/golang v0.0.0-20261018023631-f8b0792b0cd7`，IPv4/IPv6 xdb 与许可证固定为同一上游 commit `f8b0792b0cd729f5b2593f690aeed225e49c1967`。选择 Apache-2.0 许可分发，完整上游许可证一同放入镜像。`scripts/prepare-ip2region.sh` 只在镜像构建、CI 或开发准备阶段运行，固定下载地址并校验每个文件的 SHA256；应用没有下载客户端、授权设置或运行时更新任务。

数据在 `/app/ip2region`，root 所有，xdb/许可证文件权限 0444。仅新增只读镜像文件，不增加运行时 Env/Cmd/Entrypoint/Healthcheck/User/Volumes/WorkingDir/ExposedPorts。content 全量缓存为 48,400,455 字节（约 46.2 MiB）/应用进程，另有程序与少量查询结构开销。固定版本查询器会写入 I/O 计数，外层互斥保护查询与关闭；加载后查询不读磁盘、不访问网络。损坏或缺失文件不会提供伪造的归属地，只显示公网 IP 与不可用状态。

设置 → 通用与访问 → IP 归属地显示来源、数据 commit、各库头部的创建日期与双栈状态，不输入任何密钥。数据库随新镜像更新。省/市/运营商使用固定数据原值，未知字段不补造。只对通过 F7 `PublicIP` 规则的地址查库，内网/保留地址隐藏原值并显示“局域网/保留地址”，非法输入显示“无效 IP”。

## IP 统计展示口径

总体页和单用户页复用同一报告。KPI、地区排行、运营商分布与搜索基于完整筛选集合，分页仅裁剪明细，不用当前页推算总数。地区数按国家/省/市组合去重（不含未知归属地）。关联用户按 ID 去重，名称相同的不同账号仍分别计数。搜索支持 IP、地区、运营商、用户与客户端，最多 100 个字符，绑定在既有管理员 API 中。读取最多 100,000 个聚合 IP，超限失败并提示缩小时间范围，不返回不完整统计。

排行按每 IP 的播放会话次数汇总；一个会话换 IP/地区会在各自项目中出现，不能相加当作总播放次数。明细保留 IP、地区、运营商、关联用户、次数与最近时间；单用户额外显示首次时间与设备/客户端。“新 IP”按保留历史内首次观测不超过 7 天判断，首次时间独立于当前时间窗口；“异地”相对于当前用户/设备/时间范围内会话次数最多的常用地区，搜索不会改变基准。这些标签仅描述访问差异，不作为身份或风险判定。

schema 80 仅移除旧 IP 提供方的专用授权设置表；先检查没有其他提供方键，发现异常则事务失败，不触碰其他凭据或媒体表。Down 仅重建空的历史表，不复活已清理密钥。测试在 media_tool_test 专属 schema 验证 Up→Down→Up 与无关凭据字节不变。
