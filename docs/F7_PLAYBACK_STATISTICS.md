# 播放统计与公网 IP

管理员入口：播放服务 → 媒体用户 → 设备与历史 → 播放统计 / IP；全局 IP 汇总在播放服务 → IP 统计。保留天数在运维日志设置中，与日志保留天数相邻，默认 180 天（1–730 天）。

## 数据口径与生命周期

| 数据 | 原有语义 / 新语义 |
|---|---|
| `media_user_item_data` | 每用户/条目的最新续播与完成状态，仍用于原生媒体协议；原 `play_count` 是完成次数。 |
| `native_playback_sessions` | 播放准入槽与 Playing/Progress/Stopped 状态，未激活的 PlaybackInfo 草稿不算播放；无进度 5 分钟 stopped。 |
| `media_playback_events` | 每个实际播放会话 ID 一行；未看完也计一次；Progress/重试合并，302 只增加重定向次数。 |
| `duration_seconds` | 相邻有效进度增量与观测经过时间的较小值，单段最多 5 分钟；暂停、回退、无上报空档不虚构时长。 |
| `media_playback_ips` | 每播放会话/公网 IP 一行，首次与最近出现时间；按 IP 汇总使用不同事件、设备、用户的 distinct 数。 |
| `media_device_ips` | 每设备/公网 IP 一行，统计成功鉴权请求，含登录/浏览；与播放次数分开标注。 |

统计从启用时开始，不反推旧的按条目历史。保留期也限制“全部”。媒体用户删除在既有删除事务内经外键 `ON DELETE CASCADE` 删除事件、IP、设备；停用或撤销库权限保留历史。清理每分钟检查，每次最多删除 1000 行，外键同步移除事件 IP。所有统计快照经过有界队列，丢弃/写入失败仅固定文案日志，不影响 302；不采集 Token、Cookie、STRM/CDN URL。HEAD 预检不记播放。

## IP 信任边界与范围清单

统一组件为 `internal/platform/clientip`。从 TCP 对端起，只在对端属于已配置可信 CIDR 时读取 XFF（无 XFF 时使用 X-Real-IP）。由右向左止于首个不可信节点；若它非公网，不能跨过该节点去选择客户端可伪造的左侧公网 IP。排除私网、回环、链路本地、CGNAT、文档、多播/保留段及非公网 IPv6；无公网证据存空值，显示“内网访问”。历史私网不迁移/删除，只在展示时隐藏。

| 范围 | 采集 / 展示 |
|---|---|
| 管理员登录、会话、失败限流 | 统一可信链，保存公网地址；管理会话使用 `IpAddress`。 |
| 媒体鉴权、设备与会话 | 统一可信链，last_ip 与异步设备 IP 记录；IP 通过管理端展示。 |
| 播放上报、302 | 服务器确认的用户/设备/条目，统一 IP；异步事件、IP 记录。 |
| 播放器准入、外部 token 访问 | 共用管理 listener 的地址证据与准入记录；旧 IP 展示同样过滤。 |
| 请求日志 | 新的结构化 clientIp 仅公网；归属地按当前库在显示层查询，不改写原日志。管理员复制原记录功能保留原值。 |
| 告警 / 通知 | 当前无独立 IP 采集字段或通知模板；不另造 IP 数据。 |
| 插件 Host | 当前媒体/准入 DTO 明确不提供 IP/UA；保留该隔离，不扩大插件权限。 |
| 播放解析缓存 | 只使用统一公网地址参与现有缓存键；302 和 STRM 原文不变。 |

## CZ88 社区版

官方说明：`https://www.cz88.net/geo-public`、`https://www.cz88.net/help/community`。社区版采用 CZDB 二进制，分别覆盖 IPv4/IPv6，需登录并提交署名信息获得授权、下载 key 与 Base64 解密密钥。数据按 CC BY-SA 4.0 公开，授权和后续下载仍需通过官方审核。设置关于区与 IP 页面显示“IP地址位置数据由纯真CZ88提供支持”。

读取器按官方列出的 CZDB 解析项目公开格式自行实现：AES-ECB 授权头、随机填充、17 字节超级块、固定范围索引、XOR 地理字典、受限 MessagePack 整数/字符串/字符串数组。实现仅使用标准库，无新增依赖；合成夹具覆盖 IPv4/IPv6、密钥/有效期、边界、截断与损坏。没有真实库或密钥进入 Git/镜像。

下载固定为官方 HTTPS 地址 `/api/communityIpAuthorization/communityIpDbFile?fn=czdb&key=...`，不接收任意 URL，不跟随重定向，不对外查询任何 IP。ZIP 成员只内存解析，不解压任意文件；限制大小，验证 DB 长度、索引、范围、记录、授权头/有效期后才原子替换 `/data/ipgeo/current.bundle`。文件私有、密钥使用现有 master key 加密入库，并纳入备份密文校验/离线轮换。每周更新，失败 6 小时后重试并保留旧库；内存查询加 4096 条 LRU，库更新与日期变化失效缓存。无库/无 key 时只显示公网 IP，未知字段不补造。

管理员提供密钥后可在设置 → 常规 → 关于 · IP 归属地保存；后台一分钟内尝试更新。实库兼容性、授权下载与真实归属地需在取得业主密钥后补验，缺库不影响播放/统计。
