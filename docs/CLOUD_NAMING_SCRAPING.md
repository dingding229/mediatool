# 云盘、目录命名与刮削

2026-10-14 · 0.20.0-dev · 数据库迁移43

## 云盘连接

独立的“云盘连接”页面维护CloudDrive2与115官方授权，不再混入索引页面。空间与会员数据通过已连接CD2的官方GetSpaceInfo/GetCloudMemberships查询，显示当前挂载、查询时间及来源；未返回的空间/日期保持未知，不推断永久会员，也不默认CD2挂载与OAuth授权是同一账号。

## 目录模板

电影：`{title} ({year})/{title} ({year}) - {videoFormat}`

剧集：`{title} ({year})/Season {season}/{title} - {season_episode} - 第{episode}集`

- `{videoFormat}` 是0day解析的分辨率（如1080p），不是文件扩展名；未知分辨率不猜造。
- `{season_episode}` 使用明确季集标签，例如S01E04。合集只保留已确认覆盖，不补缺集；非连续覆盖继续投影成独立索引，播放仍是完整源文件。
- 原媒体和STRM扩展名自动保留；STRM仍带文件级版本标识，避免不同版次串文件。
- 禁止绝对路径、`..`、空目录组件、反斜杠和变量注入分隔符。剧集目录模板为“剧集目录/季目录/文件名”。纯文件名模板沿用标准电影/剧集目录。
- 系统设置提供纯示例预览。模板只用于新预览/新输出；旧资产须明确预览输出迁移，不自动改变原STRM正文或Key。

## 文件与历史

本地子目录可重命名及删除（可恢复）：预览后移动到受限根目录的回收区。挂载根、只读目录、做种源和托管输出不能直接修改或永久删除。

整理历史按工作阶段显示，支持移除已结束记录/批量移除；移除仅影响历史列表，原SQL恢复证据、审计、媒体及STRM保留。执行中、结果未知、待恢复记录不能移除；状态/时间变化后新证据重新可见。

## 刮削选择

- 电影：NFO、poster、backdrop、logo。
- 剧集：NFO、poster、backdrop、logo。
- 季：NFO、poster。
- 集：NFO、thumb。

默认保持电影/剧集/单集NFO，其余按需启用。图像走TMDB代理范围，固定官方图像来源，不向图像源发送API Key；限定每张8MiB、整批32MiB并校验JPEG/PNG和尺寸。图像写入使用加密持久化journal及内容哈希，未知/手工文件不能覆盖。

剧集/季共用图像以TMDB身份隔离归属，季NFO使用核验后的季ID而非剧集ID；电影和集图像按文件级版本名写入。TMDB没给图像会记录“未生成”原因，网络或非法图像失败阻止本次写入。关闭开关不会自动删除已有输出；明确迁移仍必须核对逐项写入/归档计划。

索引分为“待识别与确认、已入库资产、扫描与计划、输出恢复与归档”。身份对话框始终展示媒体类型、关键词和查询按钮，移动端堆叠。账户配置在云盘连接，刮削/模板在系统设置，避免操作混杂。
