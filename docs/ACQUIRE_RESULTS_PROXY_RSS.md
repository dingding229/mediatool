# 资源获取：结果页、代理、RSS与历史订阅

## 搜索与缓存

媒体搜索/站点直搜用于输入，结果统一进入 `/search/results/<run-id>`。最近搜索、总览和搜索缓存的查看入口进入相同路由。刷新结果页会按服务端运行ID恢复媒体身份、站点状态、全部结果及筛选；不会在输入页面插入资源列表。

TMDB/搜索缓存页面不再显示大小和有效期设置。TMDB以小时显示剩余时间；搜索记录只有Redis索引确实指向自身且未到期时显示可复用倒计时，否则显示历史结果。运行中显示查询中，不伪造缓存TTL。清理隐藏记录/停止复用，下载依赖的底层快照保留。

## 网络代理

系统设置的网络代理支持HTTP/HTTPS/SOCKS5/SOCKS5h地址，可含认证。URL加密保存且加入主密钥轮换范围，管理员原值回显；各模块明确开启，关闭的模块直连，不使用环境变量隐式代理。TMDB查询和海报、PT登录/搜索/RSS/站点下载请求分别作用；不会代理Emby/115/CD2或qBittorrent。失败不静默直连。修改代理配置使新的搜索/TMDB缓存键失效；旧搜索结果仍可查看。

## PT账号

名称/网址仍由编译Go模板确定。保存时验证Cookie/UA；用户ID自动提取，也可手工输入数字ID。自动成功且与手动ID不一致时拒绝保存。RSS可以留空自动获取，或手工填写同站有效Feed；输入不会绕过同源/XML/Feed验证。保存失败不覆盖旧凭证或旧URL。

RSS生成按实际站点表单中的成功控件，包括动态隐藏CSRF字段、默认select/radio。只允许模板声明的RSS生成表单，不提交账号设置/资料表单。OURBITS按其页面的JS表单序列化协议构造链接；TTG使用rsstools.php/putrss.php；CHDBITS优先验证带认证的下载Feed，防止先请求无认证阅读器链接触发限频。不会把猜测地址直接保存为成功。

HDSKY零结果必须同时具有本站明确空提示和认证标记；损坏响应、登录页、挑战页仍失败。站点资源随时间变化，某次零结果不是永久无资源。

## 订阅

新增拒绝下载H&R资源开关，默认开启。关闭只允许已知H&R资源；H&R未知始终拒绝自动订阅下载。相同策略在预演/正式评估/真正添加下载前复核，未知身份和来源仍不会被绕过。

“归档订阅”停用后保留订阅、评估、决策和下载关联，历史页只读，不允许重新启用或执行归档订阅。当前/历史均可查看近100次评估与决策。归档不删除媒体或做种源。

文件与入库后续分阶段规划见 `plans/20261014-files-and-library-roadmap.md`；本轮没有执行真实文件移动或PT下载。
