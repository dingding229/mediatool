# Go站点模板与账号管理

更新：2026-10-13；主程序0.13.0-dev/schema34。

## 模板

模板仓库为Go模块github.com/dingding229/mediatool-site，六站独立Go构造函数，声明名称/域名/认证字段/搜索与统计规则/RSS接口。主程序go.mod固定伪版本，通过Actions构建；运行时不读取远程JSON或编译执行远程源码。JSON Snapshot仅用于内部数据库持久化和测试，不是用户编辑或导入格式。

启动时原子登记全部内置Go模板，不要求选择导入或来源提交。相同版本/内容不改更新时间；升级改变定义指纹，旧搜索/统计/下载证明不重用。独立“站点模板”页仅显示HDSKY、OURBITS、CHDBITS、SSD、TTG、UBITS，不暴露来源地址/提交/导入列表。后台普通用户不需要操作Git版本。

## PT账号

账号页面只保留顶部统计和单一站点列表，无重复“已保存连接”表格。添加时从模板下拉选择，已有站点禁选且后端数据库唯一索引阻止并发重复添加。名称和访问地址由模板确定，不可手改。PT连接验证后直接使用，不设置“主连接/启用”复选框；其他服务的选项不变。

按模板仅展示必需认证字段；当前六站需要Cookie、User-Agent。UA按钮通过当前浏览器请求头获取，可查看/修改；请求使用保存的实际UA。用户ID从账号页面读取，不手工猜测。

编辑通过管理员会话获取全部原值，无脱敏；Cookie、UA、RSS和用户ID回显，历史其他凭据以只读原值展示。关闭表单清空前端内存，返回no-store，数据库仍主密钥加密。公开访问拒绝；建议HTTPS管理地址。

## RSS

使用已验证Cookie/UA读取真实RSS页面链接；Nexus站点可调用getrss.php的实际生成接口，SSD/UBITS按各自faqlink位置，TTG读取独立页面。只接受同源实际返回地址，并用RSS/Atom解析器校验内容，拒绝HTML认证页和跨源链接；不拼接猜测Passkey/URL。

保存自动验证登录并尝试发现RSS。获取失败保留已有地址，提示unavailable，不谎称成功；不修改站点密码、不绕过挑战。RSS地址仍按连接密钥加密保存。发现请求可能遇到站点限流/超时，此状态不代表完整真实账号验收。

## 统计

“种站点数”统计具有权威非旧快照做种数>0的站点数量，不再累加种子数量；0与未知分开。上传/下载原指标不变。每站保留同步/编辑入口。

## 保护与测试

schema34仅对内置六站的PT定义ID添加唯一索引；若旧数据重复，迁移失败，不自动删除凭据。启动不修改账号Cookie/115授权/媒体或STRM。仅app/postgres/redis官方Compose；发布仍走GitHub ActionsAMD64/Docker Hub不可变镜像。

Go模板定义、RSS实际链接/XML/UA、自动注册、PT表单名称/地址、重复保存和加密/回显及移动端均测试。对真实账号仅执行用户授权的只读检查，不把fixture或Go模板编译当真实站点全部可用。原署名/许可在模板库保留，格式改变不用于移除许可。
