# Go站点模板与账号管理

更新：2026-10-13；主程序0.14.1-dev/schema36。

## 模板

模板仓库为Go模块github.com/dingding229/mediatool-site，六站独立Go构造函数，声明名称/域名/认证字段/搜索与统计规则/RSS接口。主程序go.mod固定伪版本，通过Actions构建；运行时不读取远程JSON或编译执行远程源码。JSON Snapshot仅用于内部数据库持久化和测试，不是用户编辑或导入格式。

目录展示全部编译模板，但仅在管理员勾选并点击“加载所选模板”后原子加载。`site_template_loads` 持久化所选ID；schema35升级自动选中已有PT账号所需模板，保留原快照/凭据，其余旧快照不作为可添加站点显示。启动仅刷新已加载模板与现有账号所需模板，不再次全量加载。相同版本/内容不改更新时间；定义升级使旧搜索/统计/下载证明失效。

卡片显示英文名称、独立模板版本号、真实内置ICO与官网链接；同源提供静态图标，不再浏览器直取外站。当前六站为v1.1.1；模板版本号和内部Snapshot格式版本2是不同概念。不显示仓库来源/提交；新建账号下拉仅包含已加载模板。

CLI：`go run ./cmd/site-template-sync -ids hdsky,ssd` 加载明确ID；无`-ids`时仅刷新已加载项。

## PT账号

账号页面只保留顶部统计和单一站点列表，无重复“已保存连接”表格。添加时从模板下拉选择，已有站点禁选且后端数据库唯一索引阻止并发重复添加。名称和访问地址由模板确定，不可手改。PT连接验证后直接使用，不设置“主连接/启用”复选框；其他服务的选项不变。

按模板仅展示必需认证字段；当前六站需要Cookie、User-Agent。UA按钮通过当前浏览器请求头获取，可查看/修改；请求使用保存的实际UA。用户ID从账号页面读取，不手工猜测。

编辑通过管理员会话获取全部原值，无脱敏；Cookie、UA、RSS和用户ID回显，Passkey和历史其他凭据按标签以只读多行字段展示，长值自动换行并可复制；HTTP不支持剪贴板时提示选择文本手动复制。关闭表单清空前端内存，返回no-store，数据库仍主密钥加密。公开访问拒绝；建议HTTPS管理地址。

## RSS

使用已验证Cookie/UA读取真实RSS页面链接；Nexus站点可调用getrss.php的实际生成接口，SSD/UBITS按各自faqlink位置，TTG读取独立页面。只接受同源实际返回地址，并用RSS/Atom解析器校验内容，拒绝HTML认证页和跨源链接；不拼接猜测Passkey/URL。

保存自动验证登录并尝试发现RSS。获取失败保留已有地址，提示unavailable，不谎称成功；不修改站点密码、不绕过挑战。RSS地址仍按连接密钥加密保存。发现请求可能遇到站点限流/超时，此状态不代表完整真实账号验收。

## 统计

“已添加站点数”统计所有已添加PT账号，无论启用状态、是否采集成功或是否有种做种，不受搜索名称影响；未添加时为0。上传/下载原指标不变。每站保留同步/编辑入口。

## 搜索

资源筛选为来源、分辨率、编码、站点；关键字匹配标题及副标题，大小写不敏感、空格分隔词均需匹配。做种人数、文件大小各支持升降序，默认做种人数降序。后端按完整已取得快照排序筛选再分页，标题/原resourceId作为稳定次序，不更改原下载资源身份。前端输入350ms防抖、改变筛选回到第一页。

## 保护与测试

schema34仅对内置六站的PT定义ID添加唯一索引；若旧数据重复，迁移失败，不自动删除凭据。启动不修改账号Cookie/115授权/媒体或STRM。仅app/postgres/redis官方Compose；发布仍走GitHub ActionsAMD64/Docker Hub不可变镜像。

Go模板定义、RSS实际链接/XML/UA、选择加载/重启保留、PT表单名称/地址、重复保存和加密/回显及移动端均测试。对真实账号仅执行用户授权的只读检查，不把fixture或Go模板编译当真实站点全部可用。原署名/许可在模板库保留，格式改变不用于移除许可。

模板全选和站点数据定时刷新见SITE_METRIC_REFRESH.md。
