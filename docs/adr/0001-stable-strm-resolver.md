# ADR 0001：STRM 使用稳定解析端点

日期：2026-10-08。状态：已接受。

## 背景

115 播放 URL 可过期；不能将临时直链长期写入 STRM。用户要求固定 cloudStorage/strm302 链接，播放时再获取有效地址。

## 决策

使用 `/api/v1/cloudStorage/strm302?apiKey=<专用Key>&pickCode=<可选真实值>&path=<编码路径>`。通过 CloudDrive2 Resolve 获取当前链接；只在符合访问条件时 302。接口及固定链接由配置的公网 origin 生成。

管理/播放凭据分离，路径校验只允许指定根目录。密钥轮换可以使旧链接失效，随后重建 STRM。后续文件级令牌减少共享播放 Key 的作用范围。

CloudDrive2 当前公开请求使用 path，不接受 PickCode；没有真实值可以省略，不编造。数据模型保留 PickCode 扩展空间。

## 后果

- 直链过期与 STRM 生命周期解耦。
- 共享 Key 地址是 bearer 能力，泄露意味着允许目录的播放访问权。
- 云端移动仍需映射/重建；路径参数不是永恒文件身份。
- 特定 UA/请求头、IP、客户端重定向/Range 等必须验证；302 不会任意注入下一跳头，也无法保证观察跳转后的错误。
- Emby 本身可能代理流量，需要媒体源与客户端播放路径联动；M1 不能宣称生产 115 直连已完成。
