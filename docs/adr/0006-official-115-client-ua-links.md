# ADR0006：115官方取链独立于CloudDrive2

日期：2026-10-09。状态：实现；用户自己的开放平台授权和真实播放待验。

用户要求在CD2不能按播放器UA提供直链时使用115官方文档。选择独立open115播放连接：CD2仍用于扫描/上传，固定STRM/媒体资产和Emby用户鉴权不变；官方根据云盘内路径取得pick_code，downurl请求发送实际播放UA。

官方模式禁止整部影片由本程序代理，不自动降级CD2。CDN最多1KiB同UA206验证通过再302，否则明确报错。PKCE使用自己的AppID；二维码/凭据加密和账号/配置版本绑定；刷新使用PG行锁、成对持久化及终态停重试。

不借用CD2或他人AppID/Token，不调用私有115 Cookie接口、不伪造播放器能力、不降低HTTPS/DNS验证，也不把没有真实授权的fixture成功报告为业务完成。
