# 工作台安全边界

## 空文件密码恢复

仅部署所有者在映射到应用 `/data` 的宿主数据目录创建空 `password` 文件，例如服务器 `/root/docker/mediatool/data/password`，再执行 `docker compose restart app`。不要使用 `password.txt`，不要向文件写密码，拒绝符号链接、非空文件及组/全局可写文件。

应用认领并消费文件，通过数据库锁和标记摘要保证一次性；启动控制台打印一个20字符随机临时密码，有效30分钟。通过 `docker compose logs --tail=100 app` 在私密终端读取；不要贴到聊天或共享日志。登录必须先更换为6–20字符新密码，全部旧会话撤销；临时会话只能查询账号、改密或退出。后台不显示恢复码或提供重置入口。

打印发生在数据库提交后，若进程在提交后/打印前崩溃，可能无法取得密码；由所有者重新创建一个新的空文件触发，不重放旧标记。程序文件日志不包含该临时密码，日志查看/数据库浏览/本地文件管理也不泄露它。Docker启动日志会保留这次输出直到Docker日志轮转，属于部署所有者私密运维信息，不能把Docker Socket挂载到后台。

## 本地文件

自动发现容器可访问的 `/data`、`/mnt`、`/media`（缺失目录忽略），无需后台添加连接。操作仍经预览、确认、身份检查及不覆盖保护。伪文件、符号链接、密码/日志/私密配置/数据库目录隐藏；托管STRM和做种源受保护。未挂载宿主路径不能读取；不挂载整个宿主根目录。

## 日志与数据

应用JSON日志每文件10MiB、当前文件+4份归档，上限50MiB，清理不删除数据库审计或Docker日志。动态级别仅本次运行，默认级别直接改Compose。
PG公共业务表/Redis数据仅提供有界分页只读浏览，数据库密码、哈希、密文、Token、Cookie、签名参数和二进制隐藏。禁止任意SQL/Redis写命令。DB/cache端口仅回环，不对公网开放。

## 直接Compose配置

根目录 `docker-compose.yml` 是唯一模板，无外部.env插值。初始化命令生成私密直接值，运行后的文件0600，**不可提交生产Compose**。测试脚本使用的.env仅为隔离测试配置，不是部署参数来源。
