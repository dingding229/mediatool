# 工作台0.10：搜索、统计、插件、PWA

## 搜索
默认“自动识别”通过TMDB multi查询真实电影与剧集，并排除人物。电影和剧集可有相同数字ID，
UI以类型+ID区别。0day标题提取名称/年份作为查询线索，不把文件名推断当作最终媒体身份。
仍可手动限制电影/剧集。同名多个作品保留供用户核对，缓存按类型/标准化查询/配置区分。

站点直搜结果筛选分辨率、来源、编码、站点、最少做种、大小、免费。
后端筛选整个当前持久化搜索快照后分页，不是只筛选第一页，不修改原资源或下载绑定。
未知分辨率可单独选择；免费未知不当作免费。partial提示不会因筛选消失。

## 站点统计
PT页参考汇总+逐站布局，展示上传/下载、分享率、魔力、等级、做种数/体积。
使用配置库的user_basic_info/user_details/seeding_statistics或profile字段，缺失/挑战标未知或失败。
未证明完整的分页/空做种列表不伪造0。兼容性以站点实际定义/返回为准，不声称支持所有站点。
采集失败保留最近成功数据；账号修订/定义变化标旧快照，较慢旧请求不能覆盖较新采集。
每次最多16个启用账号，总75秒、每站15秒；其余可单站同步。没有后台自动周期任务。

## 日志与数据库
“清爽模式”改为“简约模式”。数据库浏览使用同款白色工具栏+深色逐行控制台，
有简约/详细、脱敏复制、格式化详情、PG分页和Redis游标。只读，不支持SQL/键值写入。
PG在单次分页内读一致快照；更新中跨页顺序可能改变，不是持久化数据导出工具。

## PWA
生产前端内置manifest、192/512图标、独立窗口、设置页安装指引、更新提示和通用离线页面。
必须通过有效HTTPS域名（或本机localhost开发环境）访问。公网HTTP/IP不能安装Service Worker。
Android Chrome使用“安装应用”；iOS Safari使用“分享→添加到主屏幕”。
只缓存同源无查询参数公开assets、图标和离线页；不缓存登录/会话、导航用户页面、API、
日志、数据库、115链接、STRM或媒体。断网只显示通用离线说明，不承诺离线播放/后台下载。
旧版本由用户点击应用新版本刷新，缓存只清理本应用自己的公开资源版本。

ZIP插件合约和示例见EXTENSIONS.md。所有功能仍在唯一app容器，无新增服务。
