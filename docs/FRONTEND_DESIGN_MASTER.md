# Media Tool 前端设计规范

本文件是前端界面规范；页面结构、交互约定与组件以此及 `FRONTEND_API.md` 为准。颜色、字号与间距继续沿用 `web/src/style.css` 中的语义变量，不另建第二套主题。

## 视觉与无障碍

- 靛蓝为主色，浅深主题都只使用 `--mt-*` / `--el-*` 变量，不用白底分页等脱离主题的样式。
- 主内容在 375px 到桌面宽度可用，侧栏列覆盖文档全高，内层导航占满视口并独立滚动。
- 所有操作、分页和分段选项的触控高度至少 44px；仅图标按钮必须有明确可访问名称。键盘焦点可见，遵守减少动态效果偏好。
- 页头只保留真正的主要任务（如新建订阅、添加账号），无主要任务则不设主按钮。描述讲用户用途，不堆叠实现术语。
- 页面名称与当前标签相同时省略面包屑第二段；只有一个标签的页面也省略第二段。

## 页面与唯一操作归属

| 页面 | 标签 | 主要职责 / 唯一执行归属 |
| --- | --- | --- |
| 首页 `/dashboard` | 无 | 只读汇总、待处理事项跳转、首次引导；不直接确认告警 |
| 搜索 `/search` | 搜索、搜索历史、发现推荐 | 选作品、站点搜索、发现推荐分页；结果页投递下载。历史只读 |
| 订阅 `/subscriptions` | 订阅列表、运行记录 | 分步新建、编辑、预演、运行、启停、归档 |
| 下载 `/downloads` | 下载任务、上传入库、手动添加 | 下载器同步归下载任务；上传控制、下载清理、手动种子投递；输出恢复链接到入库整理 |
| 媒体库 `/library` | 无 | 内置/Emby只读海报展示、季集浏览、复制播放链接；无配置或维护入口 |
| 入库整理 `/organize` | 待确认、扫描、已入库、整理历史、恢复与归档 | 识别确认、扫描、输出恢复、归档；物理批量整理链接到文件页 |
| 文件 `/files` | 文件浏览、STRM目录、STRM工具 | 文件变更、物理批量整理、STRM浏览/修复、播放链路诊断 |
| 播放服务 `/playback` | 服务设置、媒体用户、播放器准入、在线会话、预处理 | 媒体账号/准入/探测管理；用户全部登录撤销只在在线会话 |
| 连接 `/connections` | 115/CD2、Emby、下载器、通知渠道、TMDB/代理 | 外部服务配置、授权、检测、通知投递历史；没有通知测试发送接口则不显示发送按钮 |
| 站点 `/sites` | 站点账号、站点模板 | 账号凭据、检测、指标、采集计划、选择内置模板 |
| 插件 `/plugins` | 已安装、插件目录 | 安装、配置、权限复核、启停；详情及自定义页保留原沙箱边界 |
| 运维 `/ops` | 任务队列、备份与告警、日志、数据浏览、缓存 | 告警确认、备份恢复、日志/数据只读查看、缓存清理 |
| 设置 `/settings` | 通用与访问、命名与分类、搜索订阅、外部API、移动端、账号安全 | 配置分区保存、缓存TTL、命名分类、凭据及账号安全；TMDB/代理只提供连接页文字链接 |

相同变更操作只能有一个归属页，其他位置最多保留普通文字链接。不同业务快照的只读刷新不是重复写入。下载器配置统一归连接页，播放服务总开关只在服务设置修改。插件发现/推荐只在搜索，不在媒体库。跨页跳转保留必要对象标识与其他 query；日志和数据页不删减原值或完整 URL。

## 统一组件与交互

### 刷新

- `PageRefreshScope` 按主页面创建读取范围，`usePageRefresh` 注册当前标签的读取函数，`PageHeader` 自动渲染一个次要圆形 `RefreshButton`，可访问名称固定“刷新”。无读取内容的标签不强加按钮。
- 默认标签不要求先写入 URL 才能刷新。隐藏标签不刷新；离页时注销；并发点击只发起一轮读取，一个分区失败不阻断其他分区。
- 刷新只读取，不测试连接、不重新安装、不触发下载同步。下载器同步是显式业务操作，不冒充刷新。
- 删除分区级手动刷新按钮。错误态的“重试”仅重新读取；未知变更结果的“核对结果”保留原对账语义，不是重放。
- 刷新表单保留未保存输入，提供最新值对照，不覆盖草稿；秘密值恢复隐藏。

### 分页和子分区

- 所有分页使用 `PagePagination`：上一页 / 第 N 页 / 共 M 页 / 下一页，首尾与加载期禁用，使用主题变量。总数未知时只依据服务端 `hasNext` 或游标，不捏造总数。
- 所有同级子分区用 `.mt-segments` 分段控件：浅画布底、选中面板底、靛蓝文字与清晰边界，按钮 `aria-pressed` 同步。适用于媒体来源、发现/推荐、备份子区、缓存种类和活动类别。
- 主标签仍用 `PageTabs`，与 `?tab=` 同步，不与二级分段混淆；分段需要可分享时使用独立 query。
- 下载备份与同行操作采用相同按钮外观，但保留真实下载链接行为。

### 四态与异步安全

- `StateView` 区分 `empty`（可用但无记录）、`error`（读取失败）、`unsupported`（来源不支持）、`unauthorized`（需要授权）。不得用空列表掩盖失败。
- `AsyncResultBanner` 中 202 只为“已排队”，不表示成功。结果未知先核对原请求，不提供盲目重试。
- 危险操作用 `ConfirmAction` 明确范围，恢复/批量变更按 `PreviewApprove` 预览、批准、执行、核验；需要确认短语时不可省略。
- 修订号冲突保留草稿、重新读取并比较；只有管理员确认采用新修订后才能再次保存。
- 设置输入预填当前生效值，但无编辑不写回默认推导值；只有差异才提示。分区保存只提交修改字段。表单中不放整包“技术详情”。

## 展示文案与边界

- 空缺统一“—”；作品计数用“部作品”，文件条数不能冒充作品总数。受分页限制时明确“本页”。无海报占位不重复标题。
- 内部来源标识、摘要、指纹、工作节点ID放技术详情；发现卡显示插件名称，无法解析时使用中性服务名。管理员日志与数据库原始值是明确例外。
- 定时计划普通视图用“每2小时”“每天02:30”等描述；原cron仅在编辑框。
- 固定用语：刷新、清空访问记录、加入白名单、已停用、搜索资源；首次出现“播放器标识（UA）”。
- 插件界面使用受控容器；权限校验、沙箱和代码加载限制适用于全部插件页面。不得提供来源/提交/版本选择器、外部URL或上传安装。
- 播放由播放器跳转到115官方地址，服务器不中转；媒体库不提供网页播放、转码或流量中转。

## 媒体契约限制

内置媒体目录尚无完整作品级总数和跨页季集实体：只按当前页真实文件分组，不推测整部已收齐。Emby以真实 `parentId` 请求子项，按返回季编号分层（含第0季）。评分、大小、清晰度等没有返回时显示“—”。播放链接只读取并复制已有稳定链接，不生成临时地址。

窄屏标签采用单行横向滚动，不折行。保存使用正常宽度的主按钮，位于卡片底部左侧；禁用按钮保留清晰文字、底色和边框。页面大标题与导航名称一致，搜索页不把分段样式用于整个工作区。
