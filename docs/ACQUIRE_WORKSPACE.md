# 资源获取工作台（0.16.0-dev / schema37）

## 实际站点适配

- SSD描述从真实torrent-smalldescr容器提取，并剔除标签；CHDBITS默认incldead=0，UBITS默认incldead=1，搜索模式/区域/收藏/促销均显式声明默认值，使实际下一页仍满足同源同路径同查询校验。边界检测不放宽。
- 已验证的HTML模板声明优惠解析契约：无优惠标记为正常1；免费/折扣仍依据声明标记；未知优惠标记保留未知。退款资源按当前收费1处理，不能当即时免费。UBITS账号级促销屏蔽优先于种子上的促销图标。
- SSD/UBITS认证做种接口“没有记录”是明确空结果，只在匹配用户/源/路径/查询范围时返回0及0B。TTG从认证页做种活动标记取得数量；显式0才能证明0B，非零且无法证明完整列表时继续未知。正常/未知不得互相替代。
- XPath文本节点可读取真实文本。模板版本1.2.0、主程序固定Go依赖；解析语义指纹升级，旧搜索快照需重新搜索，不回填不可变下载证明。

## 多选与媒体信息

四类筛选均多选，同类OR、不同类AND；请求重复resolution/source/codec/accountId键，兼容原单个参数。空选择不限，完整快照筛选排序再分页。

搜索结果上方展示TMDB媒体卡片（名称/年份/类型/分类/ID/海报/背景/简介）。从TMDB作品进入保留所选身份；站点关键词仅对唯一精确标题候选自动展示，模糊/重名需选择，不把相似作品当已验证下载身份。详情和创建停用订阅入口可用，不自动启用/下载。真实详情查询复用配置及TMDB缓存，失败有提示。

## 模板与缓存

模板支持网格/列表、本地显示偏好，保留图标/版本/网址/全选/选择加载。

TMDB缓存和搜索缓存独立页面，只操作各自Redis命名空间；有分页、TTL、大小、内容预览和明确确认清理。扫描有上限/并发过期时如实显示覆盖边界；不能删除其他Redis数据或数据库搜索历史。搜索快照预览最多50项，完整内容在搜索历史中查看。缓存只存公开媒体元数据/搜索run索引，不存站点认证字段。旧TMDB数组缓存仍可查看，新格式带query/type/创建时间。

所有资源获取页面共享快捷导航、响应式布局与错误状态；下载页进度快照不代表全量业务完成，媒体卡片不绕过媒体身份确认。
