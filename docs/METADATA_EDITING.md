# 媒体文字元数据（v0.34.0）

- `media_items` 与 `native_tmdb_details` 保留入库/刮削基础值；
  `media_metadata_overrides` 按作品、季编号、集编号保存人工覆盖。
  键存在即锁定，空字符串/空数组/null 是清空，不是恢复。
- 编辑、恢复只更新覆盖表及同事务审计，不改网盘、物理版本、整理路径、NFO 或 STRM。
  扫描、入库确认、整理纠正、转存、TMDB 自动刷新仍更新各自基础表，不能清除覆盖。
- API 使用规范身份及 revision 原子比较。首次并发同样返回409；解除全部字段后保留修订号。
  前端冲突保留修改意图，重新读取后未改字段采用新值，明确核对后才可再次保存。
- 管理端与原生浏览在SQL合并有效字段后搜索/排序/筛选/分页。大字段只按页键读取，
  不把整个媒体库拉入内存过滤；原生分级权限使用有效分级。
- 分级/genres 的未编辑基础值沿用既有刮削来源；不同层级的人工覆盖独立，父级标题通过
  SeriesName/SeasonName 展示，不把父级的整份覆盖复制到子集。
- 显示 genres/tags 与目录分类分离。分类只读入库与T2b补齐的genreIds、国家、语言事实；
  编辑、恢复文字字段不改 classification、国家、语言，也不重新整理目录。
- 季/集编号纠正后，旧覆盖保留且标为“未匹配”，按作品索引分页核对；不移植到新编号。
- “恢复为刮削值”仅解除该字段锁，显示最新已存基础值。缺值显示“暂无刮削值”，不联网获取。
  标语、标签、单集评分只在之后正常刮削时补采，不运行回填任务。
- 标题/原始标题/排序标题≤500字符；简介≤10000；标语≤1000；类型/标签≤50项且每项≤100，
  去首尾空白、空项、重复项；评分0～10保存1位小数，日期合法，年份1800～2100。
- 迁移83仅新增覆盖表与复合主键；Down只移除此表。无新依赖、DB扩展或镜像启动配置变化。
