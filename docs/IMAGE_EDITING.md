# 本地图片覆盖（T4）

作品、季和集使用与文字覆盖相同的编号作用范围，但图片位于独立 `media_image_overrides`，独立 revision。键存在即锁定，恢复删除单键；空行保留 revision 防止 ABA。文字编辑不接触图片键。审计与图片引用同事务提交；条目编号变化不移植人工图片，管理端显示“未匹配”。

海报/单集缩略图映射原生 Primary，背景为 Backdrop，透明标识为 Logo。管理端列表、详情和原生分页投影在当前页批量合并图片，不改变文字搜索、排序、目录分类、STRM、网盘和 NFO。原生图片路由仍先检查实时媒体用户库权限，再读本地文件；父级图片标签同步更新。人工图片 ImageTags/ETag 使用重新编码后的 SHA256，管理图片不使用公共缓存。

上传仅接收真实格式与扩展名一致的 JPEG/PNG/WebP（10MiB、8192单边、1600万像素），拒绝动画；解码并发上限2，超限返回429，不无限排队。固定版本 golang.org/x/image v0.46.0 仅提供 WebP 解码，像素重新编码为标准库 JPEG/PNG，不复制元数据，PNG保留透明度。原文件名不作为磁盘路径。

TMDB 候选只在打开选择器或确认选中时读取固定 TMDB images 端点。选中路径必须属于对应条目的候选；固定 image.tmdb.org 下载禁止重定向、限制字节/时间并重新编码。浏览器只访问应用图片API，不直连TMDB。

文件位于原有 /data 卷的 `/data/native-media/images/`，无新环境变量/VOLUME/Compose变更。以UUID命名、安全目录根、独占原子发布；短数据库事务锁串行化引用发布与回收。只有确认无引用的本程序登记文件可以删除。正常替换/恢复立即回收，失败事务清理确定未提交文件；不确定提交保留待核对。重试须先读最新状态，不自动重放提交。

## 备份边界（明确遗留）

当前运维备份的 outputs.tar 仅包含 STRM/NFO 等托管输出；数据库备份包含图片覆盖和文件登记，**不包含本地图片字节**。完整接入需改归档、校验、恢复计划、导入与失败补偿，超过本任务约150行的小改范围，按owner要求留待专门任务。完整恢复时必须同时保留/恢复 `/data/native-media/images/` 的对应副本，不能只恢复数据库。本次部署备份额外保留图片目录，不改变内置备份格式。应用升级和回滚不移除 /data 文件。
