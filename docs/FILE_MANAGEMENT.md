# 文件管理、影视整理与独立服务配置

更新：2026-10-11。本轮包含六项用户更新；开发/部署状态以文件整理版本的验证报告为准，旧版本的验证不能替代本轮。

## 页面入口

- `/files`：浏览已启用的 CloudDrive2/115 与明确配置的本地目录；分页、上级目录、新建目录、重命名、移动、影视整理、回收/恢复和操作记录。
- `/mediaLibrary`：在“本程序入库”与“Emby媒体库”之间切换，搜索标题、筛选类型、分页、海报与简介/文件位置。Emby API Key由后端使用；海报地址不携带凭据，不读取视频流。
- `/integrations/emby`、`/integrations/clouddrive2`、`/integrations/open115`、`/integrations/tmdb` 等为各服务独立配置入口；`/integrations`仍为总览。PT账号及本地目录支持多个连接。

## 重命名与分类移动

选择文件后“影视整理”，输入明确的电影/电视剧类型、标题、年份和可选分类。目标目录填`.`时，默认生成：

- 电影：`电影/[可选分类]/标题 (年份)/自定义文件名.ext`
- 电视剧：`电视剧/[可选分类]/标题 (年份)/Season 01/自定义文件名.ext`

也可以指定允许根目录内的相对目标目录。自定义文件名和命名模板二选一，模板支持`{original}`、`{title}`、`{year}`、`{season}`、`{episode}`、`{resolution}`、`{ext}`。不猜测未填写的元数据/分辨率，不把重命名当成格式转换。影视文件保留原扩展名；例如`标题.1080p`会保留原`.mkv`。

重命名/整理可以一并处理同名字幕和NFO侧车；保留语言/forced/default后缀，idx/sub需配对。手工文件名不会自动更改影视身份；身份/NFO修正仍通过云盘索引的既有预览确认流程。

预览返回完整源/目标清单及需要创建的目录，**不改文件**。确认必须带服务端计划ID/摘要；计划10分钟有效，源身份/大小/时间和连接修订变化需要重新预览。本地采用原子no-replace重命名；CloudDrive2移动显式使用Skip、禁止跨云/递归覆盖。云端重命名先检查冲突，RPC后核对身份，不能把其非原子预检查夸大为外部并发也不会冲突。

确认成功的每一步先核对结果再同步索引，已有资产ID、文件Key及STRM正文不变；缓存版本随云盘索引时间变化。旧的纯路径/全局Key链接不具有文件级身份，不保证移动后仍可定位，应显式迁移为文件级链接。

## 删除与未知结果

“移入回收目录”不调用永久删除，将数据移动到本根目录`.media-tool-trash/操作ID/`，可通过“移动”恢复。已入库文件在回收区标为trashed，其文件级播放入口暂停；恢复后保持原Key。扫描排除回收区，不把回收文件误标为可播放。

多文件/多RPC不是云盘事务。中断、认证失败或响应丢失时持久化`needs_reconcile`，不自动重试移动或反向回滚。操作记录的“核对结果”只读取实际源/目标身份并修复索引/进度，**不重新发送变更RPC**；部分完成时需对当前文件重新预览剩余操作。正在运行或待核对时禁止同连接新扫描；扫描/未完成传输期间禁止开始文件变更。凭据轮换后同一origin可核对，未核对操作禁止改变endpoint/root。

## 本地目录与界限

本地连接必须显式填写程序容器能访问的绝对根目录。容器文件系统与服务器宿主机不是同一个路径命名空间；新增目录需按实际部署挂载且给予运行UID适当权限，不能填系统根目录。符号链接/特殊文件不允许修改或穿越，做种源目录及托管STRM/NFO目录受保护；整理本地做种源不移动原文件。

当前边界：单目录最多5000项，列表分页最多200项；单次视频整理最多64个关联侧车、160个步骤，目录变更最多500个已索引文件需要逐项核对。超过上限明确报错，请缩小子目录，不伪装成完整列表。

## 115无Token保存

新增115连接无需Access Token/Refresh Token，可只填写自己的AppID和挂载前缀（未提供前缀时缺省`/115`），保存为待授权连接。即使勾选启用，没有授权Token时也会安全保存为未启用，不宣称已授权；支持“保存并扫码授权”，授权/验证后再启用。保留已有授权和未提交的凭据；不为保存草稿调用115接口。

## 密钥回显

编辑连接后明确点击“读取已保存密钥”并确认，通过当前管理员会话、CSRF保护和连接修订检查读取所选服务支持的字段。响应no-store；列表/状态仍不回显值，审计只记字段名，内部刷新状态和程序主密钥不提供回显。默认掩码，字段旁“显示/隐藏”支持键盘操作；关闭/离开清空前端内存，不写localStorage。

未修改的回显值不重复提交，以免覆盖编辑期间服务端刚刷新的115 Token；留空仍保留原值。当前公网HTTP没有传输加密，敏感配置/回显应使用HTTPS，数据库加密不替代HTTPS。
