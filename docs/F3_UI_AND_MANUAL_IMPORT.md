# F3：稳定刷新、工作台整理与手动下载后处理

## 范围和取舍

本次不新增依赖、数据库扩展或迁移，沿用 schema 77。播放接口及 STRM 正文不变；不引入中转、HLS 或转码。管理界面的外部/内部传输仍集中于 `web/src/api/`。

### 1. 稳定加载与刷新

- 统一 `useRefresh`：单次在途请求、按完成时刻计时、页面不可见时暂停、卸载释放定时器，隐藏的页签不继续请求。
- `useResource` 区分首次 loading 与后台 refreshing；已有数据不会因刷新或失败被清空，错误覆盖提示保留重试入口。
- 迁移队列、下载/上传/手动下载、仪表盘与待处理、订阅/历史、整理、站点、运维/恢复、通知、插件面板及115授权状态检查。余下 timer 仅为输入去抖或 object URL 释放，不是网络轮询。
- 队列、日志、站点、结果和订阅采用保留空间/有界滚动工作区，避免数据量变化推移相邻内容。不按每个返回行生成假百分比。

### 2. 容量统一

`web/src/utils/format-bytes.ts` 是唯一动态容量 formatter。1024 进制，显示值达到 1000 前进位，保留两位小数，B 至 PiB；负值/非有限值/无法识别字符串显示“—”。显式带单位的后端/插件容量字符串也转换为二进制显示，未知文本不猜测。

### 3. 站点与搜索

站点原有身份、状态、指标和按钮混排，数值宽度及多账号卡片的操作基线不一致，窄屏难扫读。现在按身份/账号状态→五项对齐指标→操作排列，窄屏两列；没有另造视觉体系。

搜索结果使用可键盘操作的纯文本列头、排序箭头与现有下拉框共用排序状态。站点状态折叠为成功/失败/进行中汇总，明细限高滚动，不因站点多撑满首页。

### 4. 队列频率

旧页面同时消费每3秒 SSE tick、5秒轮询以及每15秒的重复 jobs 读取。生产改前两分钟实际观察为64次 jobs/browse、8次 operations，即业务请求36次/分钟。

新页面连接 SSE 时不启动独立轮询，将心跳合并到最多15秒一次 jobs 读取，健康30秒一次；断开时15秒回退轮询，页面不可见时关闭 SSE/暂停读取。相关 e2e 以虚拟120秒验证：包括初次读取 jobs=9、health=5；刷新前后容器 boundingBox 一致，scrollTop=120不变，CLS约0.0335。生产结果须以部署后的私有验收记录为准，不能用合成结果代替。

### 5. 日志与首页

- 日志采用参考图的筛选行、深色等宽紧凑表、着色级别、可换行消息、file:line 来源、trace/span 次行及分页。保留清空确认、配置、复制与导出，不新增无后端语义的分享/关闭功能。
- 管理员完整原值和请求/302 URL继续展示；复制导出提醒私有使用。一次性恢复密码仍只在启动 stdout，不进入日志库。
- 首页仅保留运行概览和最近搜索。首次使用引导、就绪检测和待处理收件箱移至“运维→检测与待处理”；设置中重新打开引导也指向该处，功能未删除。

### 6. 手动下载复用流水线

新建管理员手动任务冻结 `autoImport`、本地映射和清理设置，完成后排队 `download.manual.import`。标题/年份/类型唯一精确识别后，以原任务 UUID 接入既有下载任务：Reconcile→PrepareTransfers→上传→校验→ImportFile/STRM/索引→清理。不会重复添加种子。SDK 原 `Create` 仍保持下载契约，未扩大插件权限。

- 不明确身份、多个文件身份冲突、季集不明确或映射变化：保留原文件、暂停并提示人工处理。
- 清理仍必须通过现有上传/入库成功证明和做种保护。未知 H&R 状态不擅自视为安全，因此即使开启清理也可能等待现有人工审批；不会为了删除源文件而绕过保护。
- 历史任务没有新标志，不自动回溯。管理员可在手动任务详情选择准确媒体身份，再明确确认“原任务后处理”。
- 新路由：`POST /api/v1/downloads/manual/{id}/import`，必须 `confirm:true`、合法电影/剧集类型及 TMDB ID；已托管/执行中的任务不能被身份修正覆盖。已登记前端路由表及 OpenAPI。

### 7. 自查：媒体用户权限

新勾选一个可见库时，前端初始值为 `canPlay=true, canDownload=false`。可见、可播放、可下载分别标注用途；浏览权限但不能播放时提示会拒绝播放。打开已有用户使用其原始 grants，不规范化、不回填、不后台更新；取消编辑不发写请求。此变更不改变任何现有账号授权。

- 流水线集成采用测试库和自有合成小文件、受控 qB/CloudDrive/云存储边界，验证上传校验、STRM/入库和保留/清理保护；不冒充真实生产115上传。
