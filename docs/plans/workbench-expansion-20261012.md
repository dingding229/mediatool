# 工作台功能更新计划（2026-10-12）

## 范围与顺序
1. **界面统一**：日志「清爽模式」统一改为「简约模式」；PostgreSQL/Redis浏览使用同款
   顶部工具栏、深色逐行数据区、简约/详细切换和脱敏复制，保留只读约束与真实分页/游标。
2. **搜索**：TMDB默认自动搜索电影和剧集，结果带真实类型；0day名称识别提取名称/年份线索，
   同名作品不擅自决定身份。PT结果在后端对整个已取得快照筛选分辨率、来源、编码、站点、
   大小、免费系数与做种人数，不只筛选当前页，缺失属性明确标未知，保留partial提示。
3. **站点数据**：使用已导入站点定义和已配置账号读取上传、下载、分享率、等级、魔力值、
   做种数/体积；数据库保存最近成功快照，显示采集时间、失败/部分字段/旧数据。参考图片的
   汇总和站点列表，不移植示例站点、Logo或虚构统计。同步不触发下载/订阅，不做手工登录验证。
4. **插件ZIP**：支持受约束的ZIP插件包安装预览、安装/升级、设置、明确授权启停、测试运行、
   执行记录和卸载。v1支持本地声明式识别规则和现有HTTPS事件Hook，不执行Python/Shell或
   未知Go二进制，不宣称兼容MoviePilot的可执行插件。配置使用现有主密钥加密；敏感设置不
   自动回显。压缩包拒绝路径穿越/链接/重复项/压缩炸弹与不支持文件，升级默认停用并保留
   可兼容设置，修订检查避免覆盖并发修改。扩展仍在单一Go程序中，无新Docker。
5. **PWA**：Manifest、应用图标、独立窗口、安装提示和离线说明页；Service Worker仅缓存
   公开静态资源，不缓存登录页面/会话、API、媒体/STRM、数据库、日志或秘密。提供移动端
   安装指导和更新提示。普通公网HTTP/IP无法安装Service Worker：检查现有HTTPS入口；若无
   可用入口，交付PWA代码及明确HTTPS部署要求，不伪称已在HTTP公网地址可安装。
6. **测试/发布**：单元、Go race/vet、数据库/Redis隔离集成、浏览器响应式/键盘/脱敏/PWA
   回归（不得并行改同一测试DB）。推送GitHub，等待Actions AMD64 Docker Hub成功，再以
   不可变SHA镜像更新指定服务器。保持唯一Compose直接值、三主容器、原账号/授权/媒体/
   STRM和外部服务；核验原302/CDN、站点真实数据和新UI，记录不足与正常115续期例外。

## 数据迁移
仅追加站点指标快照及插件包/配置/执行状态字段；不重写已有媒体、播放Key、站点凭据。
插件密文加入离线主密钥换钥清单；数据浏览不能泄露配置密文、秘密或播放URL。

## 验收重点
- 自动类型搜索丢弃TMDB人物结果；手动指定类型仍可用；失败不缓存。
- 结果筛选总数覆盖已保存快照，下载仍绑定原资源与原搜索快照。
- 站点未知值使用“—”，汇总说明覆盖范围，失败保留成功快照但不能标为最新成功。
- 插件安装不会自动授权外传/执行；测试须明确触发、不得模拟修改真实媒体。
- PWA断网仅显示不含用户数据的离线说明，API不得从缓存取得；不增加外部遥测。
