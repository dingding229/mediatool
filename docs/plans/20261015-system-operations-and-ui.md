## 实施顺序与验收

1. **目录分类**：单列紧凑组/规则行，统一panel、状态和操作；桌面行布局，手机卡片及44px操作；保留顺序、启停、兜底和CAS保存。国家/地区与电影/剧集题材使用中文名+标准值复选框，支持选项搜索，已有未知值仍显示可勾选，不因编辑丢失。原语言保持原值编辑。
2. **整理历史**：重写条目和scoped CSS，海报、媒体/阶段/状态、来源→目标、操作分区；时间只出现一次。保留筛选、分页、步骤证据、逻辑移除与只读核对，不删除媒体，不重放未知结果。
3. **永久API凭据**：迁移49取消expires_at非空/到期约束并将已有日期置空；新增凭据不接收有效天数，鉴权无到期判断。保留随机token、加密回显、摘要鉴权、scopes、主动撤销、每分钟限额与调用审计。数据库/HTTP/UI/文档同步验证。
4. **系统运维**（本轮可交付边界）：在现有后台任务页增加运维概览，管理员只读获取PostgreSQL/Redis探测及延时、迁移版本、DB大小/连接池、进程内存、Worker心跳及离线状态、分队列状态计数与租约逾期、未投递通知。统一展示真实Cron表达式、时区、启用状态和下次执行（站点、订阅、扫描、插件、核心协调周期）；不可用不得伪装0或健康。任务增加服务端状态/类型/队列/关键词筛选、分页和完整详情。复用现有创建system.check、日志、数据库、通知及设置入口；不提供任意SQL、远程命令、通用强制重试或媒体清理。
5. **验证发布**：Vue单测/build、Go串行race/vet、Python脚本回归、隔离库E2E；1440/375截图及溢出检查。commit/push main，等待Actions的AMD64 Docker Hub不可变镜像，仅更新服务器app。前后核对授权、策略、原STRM/NFO与其他容器；限定清理本轮临时构建材料，保留回滚和私密验收收据。
