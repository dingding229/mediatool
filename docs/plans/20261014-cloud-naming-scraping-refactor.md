# 云盘、命名与刮削工作台更新计划

## 顺序与实现边界

1. **云盘连接独立页面**：导航新增“云盘连接”，CloudDrive2连接与115官方授权仅在此维护。115空间/会员信息通过已连接CloudDrive2的官方 `GetSpaceInfo` / `GetCloudMemberships` 查询，展示挂载范围、来源和查询时间；不猜测到期日期，不将CD2账户与115 OAuth账户默认为同一身份。
2. **目录级命名模板**：统一受限相对路径模板，支持 `{videoFormat}`（分辨率）和 `{season_episode}`（明确季集标签）。支持电影/剧集文件夹；自动保留原媒体扩展名及STRM扩展名。禁止绝对路径、空组件、`.`/`..`、变量注入目录分隔符。现有STRM路径和正文不自动迁移，新整理预览/新资产使用模板。
3. **本地目录动作**：子目录重命名使用完整名称输入；“删除（可恢复）”经过预览/确认移入回收目录，不永久删除挂载根、做种源或托管输出。
4. **索引工作台重构**：按“待识别/已入库/扫描与计划/输出恢复”分区；移走云盘配置。身份对话框使用独立固定三列查询布局，始终显示关键词、类型和TMDB查询按钮，移动端堆叠，错误在对话框内展示。
5. **整理历史重构**：精简列表、阶段/状态筛选和步骤详情；支持批量移除已结束历史。移除只影响显示，保留审计/输出归属/恢复证据；执行中、结果未知或待恢复记录不可移除，更新后的新状态重新可见。
6. **刮削设置**：电影（NFO/海报/背景/logo）、剧集（NFO/海报/背景/logo）、季（NFO/海报）、集（NFO/thumb）独立选择，默认延续NFO。受控TMDB图像下载、大小/格式检查、托管归属与不覆盖写入；provider缺少图像明确记录，不伪造完成。关闭选项不会自动删除已有输出。
7. **验收与发布**：FS/PG/gRPC/HTTP隔离测试、Vue、桌面及390px E2E，Go全量串行race/vet；GitHub → Actions AMD64 → Docker Hub不可变镜像 →服务器只读验收。保留实际账号、授权、原STRM及其他容器。

## 验收样例

- 用户给出的两个目录模板，中文标题、缺失年份、S00特别篇、连续/非连续覆盖和非法路径。
- 目录重命名/回收、只读挂载、做种保护、目标冲突和未知结果恢复。
- TMDB关键词输入与按钮布局、索引分区、历史移除确认与未结束保护。
- 每个刮削开关控制实际输出；图像无结果/错误/过大/非法路径/手工文件冲突；STRM正文及播放Key不变。
- 实际空间和会员信息可返回部分数据，RPC不支持显示“未返回”，不显示虚假0或猜测到期。
