# 系统运维与后台 UI 后续修复计划 · 2026-10-15

## 修复范围

1. 任务队列：统一页面标题、统计卡片、Worker/队列面板、任务表和操作区；移除重复的运维快捷链接，使用左侧系统运维导航；补充状态中文名称和队列中文名称，收紧截图所示的异常空白。
2. 日志：增加面向用户的等级、阶段、结果、错误和请求摘要；原始结构化字段与完整 URL 仍在详情中保留。请求/302 操作统一为同一组详情按钮，只有存在跳转地址才显示跳转动作。
3. 外部 API：统一标题区、面板标题、凭据卡片、最近调用表格、空状态和危险操作样式，不改变永久凭据、权限、回显和撤销行为。
4. 系统设置：补齐当前分组标题，统一设置页面和其他运维页面的面板及操作样式；TMDB 只保留单一配置入口，服务连接只展示状态。
5. 重复按钮：任务队列、维护中心、日志、连接总览、外部 API 和系统设置逐页去除同义的刷新/查看/跳转按钮；高风险确认保留。

## 不变约束

- 不删除原始日志、原始请求 URL、302 Location 或 API 凭据；只改变默认展示方式。
- 不改变 PostgreSQL/Redis 数据结构、115 授权、STRM 正文和维护安全边界。
- 仅在现有 Vue 页面做 UI/解释层改进；后端只在 TMDB 单实例约束确有缺口时增加校验。
- 先通过 Vue/Go/E2E，再推送 GitHub、发布 AMD64 Docker Hub 镜像并更新服务器。

## 具体交互与验收边界

- 日志默认中文解释，未知事件不猜测；“友好说明”可关闭。每行只有一个详情按钮，完整请求地址、Location、原始JSON与复制动作在同一个对话框中；不自动访问播放链接。
- 外部API凭据继续完整直接回显（不新增遮罩或二次查看门槛）。调用示例可展开，凭据与调用记录使用统一24px间距。
- TMDB改为只有Token的表单；语言保留当前内部设置，首次默认zh-CN。历史凭据不删除，API/Repository用同一事务锁拒绝新增第二份TMDB配置；唯一在用配置原地编辑。
- 重复跨模块快捷按钮优先删除，保留任务→维护中心这一必要父子入口。筛选查询、危险操作确认与配置保存不是重复刷新，不误删。
