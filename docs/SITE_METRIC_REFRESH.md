# 站点图标与定时数据刷新

2026-10-13，0.14.1-dev/schema36。

## 真实ICO

六个模板的真实ICO来自各站公开favicon.ico（未使用Cookie），已验证ICO文件头/浏览器解码，并作为Go模块内置资源。前端通过同源`/api/v1/pt/templates/{id}/icon?v=1.1.1`读取，返回image/x-icon、ETag及静态缓存头。不依赖浏览器跨域访问、第三方图标服务或后端任意URL代理。原站logo/商标归各站所有；公开来源和摘要记录在模板库assets/README.md。

## 全选

“全选可加载模板”只选择当前尚未加载项；部分选择时为半选状态。“取消全选”清空选择。全选不会立即加载，仍需点击“加载所选模板”；已加载模板不重复选中或重新导入。

## 定时刷新

PT站点页面提供“定时刷新”设置，默认启用、60分钟。schema36初始化后约1分钟首次调度；后续按照保存的周期执行。间隔15分钟～7天，可关闭；设置带revision防覆盖，显示下次调度时间。保存后从当前时间重新计算周期。

配置存PostgreSQL的site_metric_schedule，由原app内default调度器每15秒检查，按启用PT账号投递持久化site.metrics.refresh任务。账号独立任务，最大尝试1次，避免失败自动连续请求站点；下个周期可重新采集。任务租约沿用现有Worker机制。停用/修改设置后旧排队任务会跳过，账号停用不再请求。

手动与定时复用sitemetrics模块，每账号PG advisory lock避免并发；网络采集15秒超时。保存时核对账号revision和模板指纹，较旧/不匹配的结果拒绝覆盖。失败保留最近成功数值，更新失败状态；手动批量刷新继续其他站点。调度、采集成功/失败写入sites日志模块。

页面每30秒读取数据库快照（隐藏页停止查询、离开页面清理计时器），此轮询不会请求PT站点。关闭浏览器不影响后台定时采集。默认官方Compose仍只有app/PostgreSQL/Redis。

测试仅使用media_tool_test/Redis15，E2E开始时关闭定时采集；真实服务器验收不创建模拟PT账号或下载。
