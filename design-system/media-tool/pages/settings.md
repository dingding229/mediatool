# System settings · 2026-10-15

Seven deep-linkable groups: access, library naming/scraping, search/subscription,
proxy, TMDB, administrator, mobile/PWA. Desktop uses a compact 184px local rail;
mobile uses a contained horizontal button strip, not a second global navigation.
One neutral content column, 1000px max; consistent panel headings, explanatory
text, labeled full-width fields and 44px actions. No duplicate TMDB health panel.
Drafts survive group switches; each save targets only that functional group and
uses current database revision. Domain changes show effective URLs and listener
ports; never auto-navigate to an unverified domain or claim DNS/TLS provisioning.
The media-user root lives on its own port and rejects administrative routes.
