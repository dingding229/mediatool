# PT 配置适配边界

核心实现位于`internal/modules/sites`：HTTP请求/读取、账号验证、HTML/CSS/XPath/JSON字段解析、API搜索取种、RSS和固定来源快照。

现在支持JSON请求体、逐项数组过滤、跨字段依赖、分组资源展开与声明顺序条件；条件先规范化为有序数组再保存，避免`jsonb`重排。旧快照缺少优先级证据时必须显式同提交重新导入，不能猜测。

相同提交恢复、整批原子导入、明确兼容报告与离线审计见`docs/PT_CONFIG_COMPATIBILITY.md`。配置加载不是站点实测；时间算术偏移、PCRE差异、专用框架和浏览器挑战仍明确报告限制。
